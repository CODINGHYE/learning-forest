## 최신 변경과 검증 구분

실제 개인 연결·교재 생성에서 네트워크 권한 차단, 불명확한 근거 오류, 6개/9개 요약의 누락, 32개 응답의 잘못된 손실 설명과 역전파 갱신 혼동을 발견했다. 원문 번호 선택·필수 주제 구조 검사·검토된 기초 풀이를 적용했다. 자세한 재현과 수정은 원칙 문서 CM-022~027 및 실제 교재 검토 기록을 따른다.

자동 하네스는 키를 비운 격리 서버와 모의 OpenAI로 실행하며 유료 API를 호출하지 않는다. 실제 개인 API 호출은 사용자가 연결한 로컬 미리보기에서 별도로 확인했다. 최종 검증 근거는 보고서의 상태·HEAD·입력 해시·실행 시각이다. 문서와 커밋 뒤 최종 입력에서 재실행한다.

비전공자가 자기 말로 개념과 연결 이유를 설명하는 평가는 아직 하지 않았다. 다음은 동료 2~3명 이해도 확인, 다른 PDF 2~3개 내용 검토, 그 결과에 따른 개선이다. [전체 계획](ROADMAP.md)을 갱신하며 진행한다.
