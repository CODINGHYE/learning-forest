# 질문별 3D 장면과 쉬운 설명 설계

- 버전: 0.4.0
- 작성일: 2026-11-16 (Asia/Seoul)
- 기준: [개념지도 작성 원칙](CONCEPT_MAP_PRINCIPLES.md)
- 상태: 질문 13개와 큰 질문 4개를 웹 시제품에 구현했다. 수치·브라우저 자동 확인을 수행했으며, 학습자 이해도 검증은 아직 하지 않았다.
- 범위: 큰 질문 4개와 작은 질문 13개. 기존 지도의 질문 문구와 ID를 유지한다.

## 1. 공통 학습 경험

사용자는 `PDF 전체 숲과 의미 관계 → 개념 선택 → 뜻과 용도 → 연결 이유 → 필요할 때 시각화` 순서로 탐색한다. 각 질문의 '개념 설명'과 '언제 필요한가'가 기본 상세의 원본이다. 아래 인용문은 시각화 버튼을 눌렀을 때 보는 예제 설명의 원본이며, UI 보조 문구는 `learning-forest/content/review.json`에서 관리한다.

기본 상세에서는 3D 장면을 만들지 않는다. 시각화 버튼을 눌러 생성한 장면은 정지 상태로 시작한다. 하나의 주된 조작을 제공하고 변화 전후의 상태를 확인하게 한다. 카메라 회전은 보조 관찰이며 학습값을 바꾸지 않는다. 설명은 3D 물체에 붙이지 않고 화면의 읽기 쉬운 영역에 표시한다.

전체 화면은 상단의 큰 질문 로드맵과 아래의 선택한 질문 상세 카드로 구성한다. 큰 질문을 고르면 묶음의 세부 질문이 지도 아래에 나타나며, 세부 질문을 고르면 상세로 이동한다. 상세에서 이전·다음 질문으로 이동할 수 있고 학습자는 직접 이해 여부를 표시하거나 개인 메모를 남긴다. 이해 표시는 객관적인 숙련도 판정이 아니다. 설명은 둥근 한글 글꼴의 보통 굵기로 읽게 하고 질문 제목·영역 이름·결과값은 크기와 굵기로 구분한다. 문서별 메모는 학습 설명 원본에 섞지 않는다.

### 재사용할 다섯 가지 무대

| 무대 | 공간의 의미 | 주로 사용하는 질문 |
|---|---|---|
| S1 데이터와 분류 경계 | 가로·세로는 입력값. 자료는 2D 평면 위에 놓이며 화면 깊이는 관찰용 | Q1.1~Q1.3, Q2.1 |
| S2 계산 단계와 중간 표현 | 두 축은 해당 단계의 값, 깊이는 계산 단계. 깊이는 추가 입력 특징이 아님 | Q2.2~Q2.3 |
| S3 예측 오차와 손실 지형 | 비교 모드: 예측·정답. 지형 모드: 두 조절값과 손실 높이 | Q3.1~Q3.2, Q3.4 |
| S4 계산 경로 | 위치는 연산의 배치일 뿐 수학적 값의 크기가 아님. 연결은 실제 계산 의존성 | Q3.3, Q4.2~Q4.3 |
| S5 숫자 묶음 | 축은 배열의 인덱스. 각 블록은 숫자 하나이며 부피가 값의 크기를 뜻하지 않음 | Q4.1 |

다섯 무대는 구현을 재사용하기 위한 구분이다. 학습자는 무대 번호를 볼 필요가 없다.

### 큰 질문을 눌렀을 때

큰 질문은 전체 예고를 보여주고 세부 질문을 고르게 한다. 긴 설명을 먼저 재생하지 않는다.

| ID | 큰 질문 | 대표 장면 | 첫 설명 |
|---|---|---|---|
| G1 | 예시를 보면 무엇을 배울까? | S1에서 예시와 정답, 바뀌기 전후의 분류 경계를 비교 | 예시를 보여주면 무엇을 바꾸는지 살펴봅니다. |
| G2 | 못 푸는 문제는 어떻게 풀까? | S1의 XOR 배치와 S2의 중간 계산 결과를 같은 점 라벨로 연결 | 같은 점도 중간에 어떤 계산을 하느냐에 따라 구분하기 쉬워질 수 있습니다. |
| G3 | 틀린 답을 어떻게 고칠까? | S3의 현재 설정과 손실, S4의 영향 계산을 네 단계로 예고 | 얼마나 틀렸는지 재고, 바꿀 방향을 계산한 뒤, 실제 값을 고칩니다. |
| G4 | 계산이 많아지면 어떻게 할까? | S5 숫자 묶음과 S4 계산 기록을 함께 예고 | 데이터를 묶어 계산하고, 고칠 방향을 찾는 반복 계산을 도구에 맡깁니다. |

## 2. G1 - 예시를 보면 무엇을 배울까?

Q1에서는 실제 과일 모델의 성능을 주장하지 않는 가상 데이터를 사용한다. 가로축은 가상의 크기, 세로축은 가상의 색 측정값이며 모두 0~1 범위다. 두 종류는 원·삼각형과 글자 라벨로 구분한다.

설계용 데이터: `(0.2,0.3,0)`, `(0.3,0.2,0)`, `(0.7,0.8,1)`, `(0.8,0.7,1)`. 확인용 점은 `(0.8,0.15,0)`과 `(0.35,0.8,1)`이다. 이 가상 데이터의 정답은 `x1+x2 >= 1` 규칙으로 만들었다. 실제 데이터가 항상 이런 간단한 규칙을 따른다는 뜻이 아니다.

### Q1.1 - 사람이 모든 판단 규칙을 적어줄 수 있을까?

- 개념 이름: 규칙과 머신러닝
- 개념 설명: 규칙을 직접 쓰는 방법은 사람이 판단 기준을 정해주는 방식이에요. 머신러닝은 예시를 이용해 판단에 쓰는 숫자를 조정하는 방식입니다. 모든 문제에 같은 방법이 가장 좋은 것은 아니에요.
- 언제 필요한가: 사람이 판단 기준을 모두 적기 어려운 문제에서 예시를 이용해 기준을 조정하는 방법을 생각할 때 필요해요. 명확한 규칙으로 풀리는 문제에는 직접 규칙을 쓰는 방법도 유용합니다.

- 목표: 사람이 직접 만드는 규칙과 예시로 판단 기준을 조정하는 접근의 차이를 안다.
- 예상 질문: '새 예시에도 큰 것은 모두 같은 종류라는 규칙이 맞을까요?'
- 3D 장면: S1의 평면 위에 가상 과일 점 네 개를 배치한다. '크기가 0.5 이상'이라는 조건을 나타내는 수직 경계를 놓는다. 학습용 네 점에는 맞지만, 확인용 두 점을 추가하면 오분류가 나타난다. 점의 위치는 그대로 유지한다.
- 주된 조작: `새 예시 보기`. 새 점과 그 정답만 추가한다. 잘못 분류한 점에는 색 외에 '예측 ≠ 정답' 표시를 붙인다.
- 화면 설명:

  > 처음 네 예시는 ‘크기가 0.5 이상이면 종류 1’이라는 규칙으로 나눌 수 있어요.
  > 새 예시 두 개를 추가하면 이 규칙에 맞지 않는 경우가 나타납니다. 정답이 바뀐 것이 아니라, 처음 규칙만으로는 부족했던 거예요.
  > 규칙이 명확한 일은 사람이 직접 적어줄 수 있어요. 다양한 예시에서 판단 기준을 찾아야 할 때는 학습하는 방법도 사용할 수 있습니다.

- 이름 붙이기: 규칙 기반 접근, 데이터 기반 학습.
- 이해 확인: '새 예시가 틀렸을 때, 정답을 바꿔야 할까요, 판단 기준을 살펴봐야 할까요?'
- 연결: Q1.2. '예시와 정답을 주면 컴퓨터 안에서 무엇이 바뀔까요?'
- 주의: 사람이 어떤 규칙도 만들 수 없다는 결론을 내리지 않는다. 여기서는 가상의 단순한 규칙 하나의 한계를 관찰한다.
- 교재 연결: PDF 4~8쪽의 학습·인공신경망 소개.

### Q1.2 - 컴퓨터는 예시와 정답에서 무엇을 배울까?

- 개념 이름: 가중치와 편향
- 개념 설명: 가중치는 입력의 각 특징을 얼마나 반영할지 정하는 숫자예요. 편향은 판단 기준의 위치를 옮기는 숫자입니다. 학습은 이런 숫자를 예시와 정답을 이용해 조정하는 과정을 포함해요.
- 언제 필요한가: 같은 입력에서도 예측이 달라지도록 판단 기준을 조정할 때 사용해요. 예시와 정답은 두고, 입력의 반영 정도와 기준 위치를 바꿉니다.

- 목표: 학습할 때 입력·정답과 조정 가능한 값의 역할을 구분한다.
- 예상 질문: '학습 전후에 달라지는 것은 예시일까요, 판단에 쓰는 숫자일까요?'
- 3D 장면: Q1.1의 같은 점과 정답을 고정하고, 두 입력을 얼마나 반영할지 정하는 손잡이 `w1`, `w2`와 기준을 옮기는 손잡이 `b`를 표시한다. 각 손잡이에 따라 평면 위 경계선이 돌아가거나 이동한다.
- 주된 조작: `학습 전·후 비교`. 예시는 같은 위치에 있고 설정값과 경계가 바뀌는 것을 보여준다. 전후 값은 검증한 실제 계산 결과를 사용한다. 미리 계산한 상태를 재생하는 경우 '학습 결과 재생'이라고 표시한다.
- 화면 설명:

  > 점의 위치와 정답 표시는 학습 전후에 그대로입니다. 바뀌는 것은 크기와 색을 얼마나 반영할지 정하는 숫자예요.
  > 이 숫자가 바뀌면 두 종류를 나누는 선도 달라집니다. 이처럼 판단에 쓰는 숫자를 예시에 맞게 조정하는 것이 학습입니다.
  > 이 장면의 결과는 가상의 예시 여섯 개에 대한 것입니다. 다른 실제 자료도 모두 맞힌다는 뜻은 아니에요.

- 이름 붙이기: 가중치, 편향, 파라미터, 지도학습.
- 이해 확인: '같은 예시를 넣었는데 답이 달라졌다면 무엇이 바뀌었을까요?'
- 연결: Q1.3, Q3.1. '처음 값은 어떻고, 더 나은 값인지 어떻게 확인할까요?'
- 주의: 이진 선형 모델을 설명하는 장면이다. 임의의 신경망 전체가 손잡이 세 개라는 인상을 주지 않는다.
- 교재·실습: PDF 13~24쪽, 퍼셉트론 노트북 셀 4의 모델 명세.

이 장면의 학습 전후 수치 예시는 다음과 같이 고정한다. 중간 과정을 설명하기 전의 학습 예고이며, 단층 퍼셉트론 실습의 갱신 공식을 그대로 적용한 장면으로 표시하지 않는다.

```text
두 입력을 각각 0.5만큼 빼서 가운데를 0으로 맞춘다.
예측 확률 = sigmoid(w1*(x1-0.5)+w2*(x2-0.5)+b_center)
정답 1의 예측 기준: 확률 >= 0.5

시작: w1=0, w2=0, b_center=0 -> 모든 점의 확률 0.5
학습 데이터 네 점의 평균 이진 교차엔트로피를 이용한다.
학습률 1로 한 번 갱신: w1=0.125, w2=0.125, b_center=0
원래 입력 좌표에서 같은 경계: 0.125*x1+0.125*x2-0.125=0
```

시작 상태에는 유일한 경계선이 없으므로 임의의 선을 그리지 않는다. '모든 예측이 0.5'로 표시한다. 학습 후에는 이 가상 데이터의 학습점과 확인점이 모두 맞지만 실제 데이터의 성능 보장으로 해석하지 않는다. 숫자를 가운데로 옮긴 것은 계산 편의를 위한 보충 전처리임을 펼침 설명에 밝힌다.

### Q1.3 - 처음에는 왜 틀린 답을 낼까?

- 개념 이름: 초기화
- 개념 설명: 초기화는 학습 전에 사용할 숫자의 시작값을 정하는 일이에요. 아직 조정하지 않은 숫자로 만든 첫 답은 틀릴 수 있어요. 첫 답을 맞히는 일과 여러 예시를 이용해 좋은 기준을 찾는 일은 다릅니다.
- 언제 필요한가: 학습을 시작하기 전에 가중치 같은 숫자의 시작값을 정할 때 필요해요. 시작할 때의 답과 학습한 뒤의 답을 구분하게 해줍니다.

- 목표: 아직 데이터에 맞추지 않은 초기 설정과 학습 후의 설정을 구분한다.
- 예상 질문: '처음 설정한 숫자가 다르면 첫 답도 달라질까요?'
- 3D 장면: 같은 데이터 위에 초기 경계 하나를 표시한다. 초기 설정을 바꾸면 선과 첫 예측이 바뀌고, 고정된 검증된 학습 상태와 비교할 수 있다.
- 주된 조작: `다른 시작값 보기`. 재현 가능한 초기값 세트를 순환한다. 정답 라벨과 데이터 위치는 고정한다.
- 화면 설명:

  > 학습을 시작하기 전에도 모델에는 판단에 쓰는 숫자가 들어 있습니다. 그 숫자를 어떻게 정했는지에 따라 첫 답이 달라져요.
  > 아직 예시에 맞춰 조정하지 않았으므로 틀릴 수 있습니다. 우연히 여러 답을 맞히는 시작 설정도 있어요.
  > 처음 몇 개를 맞혔다는 사실만으로 잘 배웠다고 판단하지는 않습니다. 새로운 예시에서도 확인해야 해요.

- 이름 붙이기: 초기화, 예측, 학습 전·후.
- 이해 확인: '첫 답을 우연히 맞혔다면 다른 예시도 모두 맞힐까요?'
- 연결: Q2.1. '잘 조정해도 지금 방식으로 못 푸는 문제가 있을까요?'
- 주의: 단층 퍼셉트론 실습의 0 초기화와 다층 신경망의 일반적인 무작위 초기화를 구분한다. 모든 모델이 반드시 처음부터 틀린다고 설명하지 않는다.
- 교재·실습: PDF 19~24쪽, 퍼셉트론 노트북 셀 4~10.

## 3. G2 - 못 푸는 문제는 어떻게 풀까?

입력 네 점은 `(0,0)`, `(0,1)`, `(1,0)`, `(1,1)`로 고정한다. AND·OR·XOR을 비교할 때에는 정답 규칙이 달라지는 것임을 표시한다. 초기 과일 예제에서 논리 문제로 전환했다는 안내도 붙인다.

### Q2.1 - 두 종류의 점을 선 하나로 나눌 수 있을까?

- 개념 이름: 선형 분리와 XOR
- 개념 설명: 선형 분리는 두 종류의 점을 직선 하나로 나눌 수 있는지를 보는 것이에요. XOR은 두 입력이 서로 다를 때만 정답이 1인 규칙입니다. 이 규칙의 네 점은 평면에서 직선 하나로 완전히 나눌 수 없어요.
- 언제 필요한가: 잘못된 답이 숫자를 덜 조정해서인지, 계산 방식 자체의 한계인지 살펴볼 때 필요해요. 선 하나로 풀 수 없는 배치는 다른 표현을 고민하게 합니다.

- 목표: 조절 부족과 모델 표현 방식의 한계를 구분한다.
- 예상 질문: '선 하나로 두 종류를 나눌 수 없는 배치도 있을까요?'
- 3D 장면: S1에서 점 네 개가 바닥 평면에 놓인다. AND·OR에서는 선 하나로 정답 집단을 나누고, XOR에서는 같은 집단이 서로 대각선에 놓인다. 경계선은 바닥의 직선이며 보조 세로막은 그 선을 보기 쉽게 표시하는 장치다.
- 주된 조작: `경계선 움직이기`. 각도와 위치를 한 번의 드래그로 조절하고, 틀린 점 개수를 표시한다. 데이터셋 선택은 비교를 위한 보조 조작이다.
- 화면 설명:

  > 네 점을 두 종류로 나눠봅시다. AND와 OR 배치에서는 직선 하나로 두 종류를 나눌 수 있어요.
  > XOR에서는 같은 종류가 대각선 양 끝에 놓입니다. 이 배치는 어떤 직선 하나를 골라도 네 점을 모두 나눌 수 없습니다.
  > 이때는 같은 선을 더 오래 조절하기보다, 입력을 계산하는 방식을 바꿔볼 필요가 있어요.

- 이름 붙이기: 선형 분리, 단층 퍼셉트론의 한계, XOR.
- 이해 확인: '이 경우에는 같은 선을 계속 조정할까요, 계산 방식을 바꿔볼까요?'
- 연결: Q2.2.
- 주의: 몇 번 드래그해서 실패한 것을 불가능의 증명으로 제시하지 않는다. 보충 장면에서는 두 집단을 잇는 대각선이 교차한다는 점을 이용해 설명한다. 카메라 회전으로 XOR이 풀렸다고 표시하지 않는다.
- 교재·실습: PDF 25~27쪽, Logic Gate 노트북 셀 14~29.

### Q2.2 - 계산을 여러 단계로 나누면 무엇이 달라질까?

- 개념 이름: 중간 표현과 신경망
- 개념 설명: 신경망은 작은 계산들을 연결해 입력에서 예측을 만드는 방법이에요. 중간 표현은 처음 입력을 어떤 계산에 통과시켜 얻은 값입니다. 같은 입력도 중간 계산 방식에 따라 구분하기 쉬운 모습으로 표현할 수 있어요.
- 언제 필요한가: 처음 입력만으로 구분하기 어려운 관계를 중간 계산으로 표현할 때 사용해요. 단계를 늘리기만 하면 모든 문제가 해결되는 것은 아닙니다.

- 목표: 중간 표현을 계산하고 그 결과를 다시 쓰는 구조를 관찰한다.
- 예상 질문: '같은 입력에 중간 계산을 더하면 최종 답이 달라질까요?'
- 3D 장면: S2에서 원본 평면, 중간 계산 평면, 출력 평면을 깊이 방향으로 배치한다. 같은 점의 라벨을 유지한 채 계산 결과 위치로 이동한다. 깊이축 라벨은 '계산 단계'다.
- 주된 조작: `다음 계산 단계`. `h1=max(0,x1-x2)`, `h2=max(0,x2-x1)`를 적용한 결과를 보여준 뒤 두 값을 더한다. 중간 계산 두 개에 서로 반대 방향의 차이를 사용하는 이유를 색 대신 방향 표시와 숫자로 구별한다.
- 화면 설명:

  > 이번에는 처음 입력으로 곧바로 답을 내지 않고, 중간 계산을 두 개 해봅니다.
  > 두 입력의 차이를 서로 반대 방향으로 구하고, 음수는 0으로 바꿉니다. 그 두 결과를 더하면 두 입력이 다른 경우만 1이 됩니다.
  > 새로운 데이터를 가져온 것이 아닙니다. 같은 입력을 다른 숫자로 표현한 거예요. 여기서는 계산 방법을 미리 정해두었고, 자동 학습한 장면은 아닙니다.

- 이름 붙이기: 중간 표현, 은닉층, 다층 퍼셉트론.
- 이해 확인: '입력 데이터가 새로 생겼나요, 같은 입력을 다른 값으로 계산했나요?'
- 연결: Q2.3. '중간 계산이 곱하기와 더하기뿐이어도 같은 효과가 날까요?'
- 주의: 이 장면은 미리 정한 계산으로 XOR을 풀 수 있음을 보인다. 가중치를 자동 학습한 결과라고 표시하지 않는다. 같은 좌표로 겹치는 `(0,0)`과 `(1,1)`의 라벨은 각각 확인할 수 있게 한다.
- 교재 연결: PDF 29쪽, 36~40쪽.

### Q2.3 - 곱하고 더하기만 반복해도 충분할까?

- 개념 이름: 비선형성과 ReLU
- 개념 설명: 곱하고 더하는 선형 계산만 여러 번 연결하면 전체를 하나의 선형 계산으로 정리할 수 있어요. ReLU는 음수는 0으로, 그 밖의 값은 그대로 내보내는 함수입니다. 이런 비선형 계산을 넣으면 표현할 수 있는 관계가 달라져요.
- 언제 필요한가: 여러 계산 단계가 하나의 선형 계산과 다른 관계를 표현하게 할 때 필요해요. ReLU는 음수를 0으로 바꿔 비선형 변화를 넣는 한 가지 방법입니다.

- 목표: 여러 층의 의미와 비선형 활성화의 역할을 연결한다.
- 예상 질문: '계산 단계가 많기만 하면 더 다양한 문제를 풀 수 있을까요?'
- 3D 장면: Q2.2의 같은 단계 구조를 유지한다. `음수를 0으로 바꾸기`를 끄면 중간 값은 `h1=x1-x2`, `h2=x2-x1`이고 합은 모두 0이다. 켜면 출력은 XOR 정답과 같아진다. 다른 점을 손으로 끌어 옮기지 않는다.
- 주된 조작: `음수 처리 켜기·끄기`. 상태를 바꿀 때 실제 함수 결과로 점들을 이동시킨다.
- 화면 설명:

  > 음수를 그대로 두면, 이 예시의 두 중간 값은 서로 반대여서 더했을 때 모두 0이 됩니다.
  > 음수를 0으로 바꾸면 결과가 달라집니다. 두 입력이 다를 때만 최종 값이 1이 되어 구분할 수 있어요.
  > 곱하고 더하는 계산만 반복하면 전체를 하나의 같은 종류 계산으로 정리할 수 있습니다. 여러 층의 역할을 살리려면 이런 비선형 변화도 필요해요.

- 이름 붙이기: 선형 계산, 비선형 활성화, ReLU.
- 이해 확인: '지금 결과가 달라진 이유는 층 수인가요, 중간 계산 방식인가요?'
- 연결: Q3.1. '표현할 수 있다는 것과 잘 학습했다는 것은 어떻게 구분할까요?'
- 주의: 활성화를 끈 특정 구성에서 출력이 전부 0이 된다는 사실을 모든 선형 신경망의 출력이 0이라는 주장으로 확대하지 않는다. 층을 늘리면 성능이 반드시 오른다고 설명하지 않는다.
- 교재 연결: PDF 29~34쪽.

## 4. G3 - 틀린 답을 어떻게 고칠까?

### 네 질문에 공통으로 사용하는 작은 계산

복잡한 분류 모델 대신 변화의 방향을 쉽게 확인하는 숫자 예제로 전환한다. 화면에 이 전환을 표시한다.

```text
조절값: u=1, v=1
중간 계산: a=2u
예측: p=a+u+v=3u+v
정답: 8
틀린 정도: L=(p-8)^2
시작 상태: a=2, p=4, L=16
```

S3의 가로축은 `u`, 세로 바닥축은 `v`, 높이는 `L`이다. 여기서 점은 학습 데이터가 아니라 '조절값 한 쌍'이다. `3u+v=8`인 여러 조합이 모두 손실 0이므로 지형의 바닥은 하나의 점이 아니라 선이다.

### Q3.1 - 정답과 얼마나 다른지 어떻게 잴까?

- 개념 이름: 오차와 손실
- 개념 설명: 오차는 예측과 정답 사이의 차이예요. 손실은 예측이 얼마나 잘못됐는지 비교할 수 있게 정한 숫자입니다. 차이를 제곱하는 것은 손실을 정하는 한 가지 방법이며, 문제에 맞는 방법을 선택해요.
- 언제 필요한가: 여러 예측이나 모델 설정 중 어느 쪽이 나은지 비교할 때 필요해요. 예측과 정답의 차이를 나타내고, 그 틀린 정도를 비교할 수 있는 손실 숫자로 정합니다.

- 목표: 예측을 비교 가능한 숫자 하나로 평가하는 역할을 이해한다.
- 예상 질문: '예측 4와 12는 정답 8에서 각각 얼마나 떨어져 있나요?'
- 3D 장면: S3 비교 모드에서 예측과 정답을 숫자 축 위의 두 표식으로 보여준다. 손실 기둥 높이는 차이의 제곱과 정확히 일치한다. 예측 4·8·12를 비교하면 정답 8에 대해 손실은 16·0·16이다. 다음에 손실 지형으로 전환해 같은 손실을 높이로 보여준다.
- 주된 조작: `예측값 움직이기`. 정답은 8로 고정한다. 작은 답과 큰 답 모두 정답에서 멀수록 기둥이 커진다.
- 화면 설명:

  > 여기부터는 변화를 쉽게 보기 위한 숫자 예제를 사용합니다. 정답은 8로 고정되어 있어요.
  > 예측이 4라면 정답과 4만큼 다릅니다. 예측이 12여도 4만큼 다릅니다. 이 차이를 제곱하면 둘 다 16이 돼요.
  > 이렇게 틀린 정도를 숫자 하나로 정하면 어떤 설정이 더 나은지 비교할 수 있습니다. 문제에 따라 틀린 정도를 정하는 방법도 달라질 수 있어요.

- 이름 붙이기: 손실함수, 제곱오차. 여러 예시의 제곱오차를 평균하면 MSE.
- 이해 확인: '예측 4와 12 중 무엇이 정답 8에 더 가까울까요?'
- 연결: Q3.2. '틀린 정도가 16이라는 사실만으로 무엇을 바꿀지 알 수 있을까요?'
- 주의: 한 샘플의 제곱오차와 여러 샘플의 평균을 구분한다. 모든 문제에서 같은 손실함수를 사용한다고 말하지 않는다.
- 교재 연결: PDF 64~67쪽. 이 장면의 보충 설명에서 분류용 손실도 다를 수 있음을 연결한다.

### Q3.2 - 숫자를 조금 바꾸면 결과는 어떻게 달라질까?

- 개념 이름: 미분과 변화율
- 개념 설명: 미분은 지금 위치에서 입력을 아주 조금 바꾸면 결과가 어느 방향으로 얼마나 변하는지 나타내요. 학습에서는 가중치 같은 조절값이 바뀔 때 손실이 어떻게 변하는지 구합니다. 멀리 움직인 뒤에도 같은 변화가 계속된다는 뜻은 아니에요.
- 언제 필요한가: 손실을 줄이려고 조절값을 어느 방향으로 바꿀지 알아볼 때 사용해요. 미분은 오차를 만드는 도구가 아니라 현재 위치에서 변화의 방향과 크기를 구하는 방법입니다.

- 목표: 현재 값 근처에서 조절값의 작은 변화와 손실 변화를 연결한다.
- 예상 질문: '첫째 손잡이 u를 조금 키우면 틀린 정도가 줄어들까요?'
- 3D 장면: S3 손실 지형에 현재 점 `(1,1,16)`을 표시한다. v를 고정한 채 u 방향의 짧은 경사와 점의 이동을 보여준다. 그 뒤 v 방향도 같은 방식으로 비교한다. 점이 나타내는 조절값과 예측값을 별도로 표시한다.
- 주된 조작: `조금 바꿔보기`. u 또는 v를 선택해 0.01씩 바꾼다. 기본은 u를 1에서 1.01로 바꾸며, p는 4에서 4.03, L은 16에서 15.7609로 바뀐다.
- 화면 설명:

  > 이 계산에는 바꿀 수 있는 손잡이가 두 개 있습니다. 첫째 손잡이를 u, 둘째 손잡이를 v라고 부릅니다.
  > 예를 들어 시작 상태에서 u를 0.01 키우면 예측은 4에서 4.03으로 바뀌고, 틀린 정도는 16에서 15.7609로 줄어듭니다.
  > 미분은 현재 위치에서 이런 작은 변화의 방향과 크기를 계산하는 방법입니다. 멀리 이동한 뒤에도 계속 같은 방향이 좋다고 보장하는 것은 아니에요.

- 이름 붙이기: 변화율, 미분, 기울기.
- 이해 확인: '현재 위치에서 줄어드는 방향이라면, 아주 멀리 움직여도 계속 줄어들까요?'
- 연결: Q3.3. '바꿀 숫자가 아주 많아지면 이 영향을 어떻게 계산할까요?'
- 주의: 실제 0.01 변화로 계산한 비율은 -23.91이고 정확한 현재 미분값은 -24다. 둘을 같은 숫자로 표시하지 않는다. 근처의 방향 정보와 먼 곳의 결과를 구분한다.
- 교재 연결: PDF 69~71쪽.

### Q3.3 - 왜 결과부터 거꾸로 따라갈까?

- 개념 이름: 역전파와 연쇄법칙
- 개념 설명: 연쇄법칙은 여러 계산을 거친 변화의 영향을 이어서 구하는 규칙이에요. 역전파는 마지막 손실에서 거꾸로 따라가며 여러 조절값의 기울기를 효율적으로 계산하는 방법입니다. 기울기를 구하는 동안 조절값 자체를 바꾸지는 않아요.
- 언제 필요한가: 많은 조절값이 손실에 미치는 영향을 효율적으로 계산할 때 사용해요. 연결된 계산의 변화율을 거슬러 구하고 여러 길로 오는 영향은 합칩니다. 실제 값 갱신은 별도입니다.

- 목표: 연쇄법칙, 분기 영향의 합산, 중간 결과 재사용을 함께 관찰한다.
- 예상 질문: '첫째 손잡이 u는 예측에 한 길로만 영향을 줄까요?'
- 3D 장면: S4에 `u → a=2u → p`, `u → p`, `v → p`, `p → L`을 배치한다. 깊이는 경로 구분용이다. 먼저 실제 값이 앞으로 흐르고, 다음에는 변화율이 뒤로 전달된다. 마지막까지 u와 v는 1로 고정한다.
- 주된 조작: `역방향 한 단계`. L에서 p로 전달되는 -8을 한 번 구해 표시하고, a 경로와 u 직접 경로로 재사용한다. 두 경로가 u에서 만날 때 -16과 -8을 더해 -24가 된다. v는 -8이다.
- 화면 설명:

  > u는 예측에 두 길로 영향을 줍니다. 한 번은 두 배가 된 뒤 더해지고, 다른 한 번은 그대로 더해집니다.
  > 마지막의 틀린 정도에서 거꾸로 계산하면 이미 구한 영향을 앞쪽에서도 다시 사용할 수 있어요. u로 오는 두 길의 영향은 합칩니다.
  > 이 과정은 손잡이마다 어떤 영향이 있는지 계산하는 단계입니다. 손잡이의 숫자는 아직 바꾸지 않았어요.

- 이름 붙이기: 연쇄법칙, 역전파, 기울기.
- 이해 확인: '역방향 계산이 끝난 지금 u와 v도 이미 바뀌었을까요?'
- 연결: Q3.4, Q4.2. '계산한 방향으로 실제 값을 바꾸고, 이 계산 기록을 도구가 다루는 방법도 살펴봅니다.'
- 주의: 영향은 부호 있는 변화율이다. 물리적 신호가 흘러간 양이나 잘못의 책임 비율로 설명하지 않는다. 이 작은 예시에서는 분기 재사용을 보여주고, 큰 그래프에 대한 계산량 비교는 추가 구현으로 분리한다.
- 교재 연결: PDF 71~78쪽.

### Q3.4 - 조금씩 여러 번 고치면 어떻게 달라질까?

- 개념 이름: 경사하강법과 학습률
- 개념 설명: 경사하강법은 기울기를 이용해 손실이 줄어드는 방향으로 조절값을 갱신하는 방법이에요. 학습률은 한 번 바꾸는 크기를 정합니다. 너무 크게 움직이면 오히려 손실이 커질 수도 있어요.
- 언제 필요한가: 구한 기울기를 이용해 실제 조절값을 바꿀 때 사용해요. 학습률은 한 번 바꾸는 크기이며, 너무 크면 손실이 커질 수 있습니다.

- 목표: 기울기 계산과 갱신을 구분하고, 학습률에 따른 경로를 비교한다.
- 예상 질문: '같은 방향이라도 한 번에 너무 크게 바꾸면 어떻게 될까요?'
- 3D 장면: S3의 같은 지형 위에서 현재 조절값 점이 움직이고 경로가 남는다. 각 점에는 그 상태의 예측과 손실을 연결한다. 공이 물리 법칙으로 굴러가는 장면 대신 계산된 갱신 위치를 순서대로 표시한다.
- 주된 조작: `한 번 고치기`. 보조로 걸음 크기 0.005·0.025·0.15를 선택한다. 모든 비교는 같은 시작값에서 시작한다.
- 화면 설명:

  > 앞에서 구한 기울기를 이용해 두 손잡이 값을 실제로 바꿔봅니다. 바뀐 위치에서는 기울기를 다시 구해요.
  > 같은 시작점에서 중간 걸음 0.025를 선택하면 이 예제의 틀린 정도는 16, 4, 1 순서로 줄어듭니다.
  > 큰 걸음 0.15에서는 첫 이동부터 64로 커집니다. 바꿀 방향을 아는 것과 한 번에 얼마나 움직일지 정하는 것은 다른 문제예요.

- 이름 붙이기: 경사하강법, 학습률, 반복 갱신.
- 이해 확인: '손실이 커졌다면 지금보다 더 큰 걸음으로 계속 가는 게 좋을까요?'
- 연결: Q4.1, Q4.3. '숫자가 많아지면 이런 계산을 묶어서 하고 도구에 맡길 수 있을까요?'
- 수치 기준: 학습률 0.025에서 첫 갱신은 `(u,v)=(1.6,1.2)`, p=6, L=4다. 두 번째는 `(1.9,1.3)`, p=7, L=1이다. 0.15에서는 첫 갱신 뒤 p=16, L=64가 되어 커진다.
- 주의: 반복 한 번과 epoch을 동일시하지 않는다. epoch은 전체 학습 데이터에 대한 한 번의 순회를 말한다. 이 예제의 모든 갱신이 좋은 일반화나 전역 최적해 보장을 뜻하지 않는다.
- 교재 연결: PDF 70쪽, 80~84쪽.

## 5. G4 - 계산이 많아지면 어떻게 할까?

### Q4.1 - 숫자들을 묶으면 계산이 어떻게 달라질까?

- 개념 이름: 텐서와 행렬 연산
- 개념 설명: 텐서는 숫자를 규칙적인 배열로 다루는 방식이에요. 행렬은 행과 열로 놓은 숫자 배열이며, 행렬 연산으로 여러 숫자를 함께 계산할 수 있습니다. 배열 모양만 바꾸는 일과 새 출력값을 계산하는 일은 구분해요.
- 언제 필요한가: 많은 예시와 특징의 숫자를 규칙적인 구조로 다루고 한꺼번에 연산할 때 사용해요. 배열 모양만 바꾸는 일과 새로운 값을 계산하는 일은 구분합니다.

- 목표: Tensor의 구조와 여러 예시를 함께 계산하는 행렬 연산을 연결한다.
- 예상 질문: '숫자 12개를 다른 모양으로 펼치면 값 자체도 바뀔까요?'
- 3D 장면: S5에 0~11을 담은 `shape=(2,2,3)` 블록을 놓는다. 축은 예시 번호·행·열이다. 예시 두 개를 각각 길이 6으로 펼쳐 `X.shape=(2,6)`인 판으로 만든 뒤, `W.shape=(6,2)`와 계산해 출력 `(2,2)`를 보여준다. 값은 동일하고 형태만 바꾸는 단계를 먼저 관찰한다.
- 주된 조작: `묶음 펼치기`. 블록과 표의 같은 원소가 함께 강조된다. 이후 행렬곱 한 행을 선택해 어떤 값이 곱해지고 더해지는지 보여준다.
- 화면 설명:

  > 처음에는 0부터 11까지 숫자 12개가 두 묶음에 나뉘어 있습니다. 한 묶음은 2행 3열이에요.
  > 각 묶음을 한 줄로 펼쳐도 숫자는 그대로입니다. 모양만 2행 6열로 바뀌어요.
  > 그다음 행렬곱을 하면 새 출력 네 개가 계산됩니다. 텐서는 이런 숫자 묶음을 다루는 표현이며, 항상 3D 상자 모양인 것은 아닙니다.

- 이름 붙이기: Tensor, shape, 배치, 행렬곱.
- 이해 확인: '숫자 12개를 다른 모양으로 펼쳤다면 숫자 자체도 달라졌을까요?'
- 연결: Q4.2. '숫자를 계산한 순서까지 기록해 두면 무엇이 좋을까요?'
- 수치 기준: X의 첫 행은 `[0,1,2,3,4,5]`, 둘째 행은 `[6,7,8,9,10,11]`. W의 행은 `[1,0]`, `[0,1]`이 세 번 반복된다. 결과는 `[[6,9],[24,27]]`이다.
- 주의: Tensor의 축 개수와 각 축의 크기, 원소 수를 구분한다. 묶었다는 이유만으로 항상 더 빠르다고 단정하지 않는다. 인덱스 차원과 화면의 공간 차원은 다르다.
- 교재·실습: PDF 47~57쪽, Tensor 노트북 셀 11~15 및 26~31.

### Q4.2 - 계산한 과정을 기억해 두면 무엇이 좋을까?

- 개념 이름: 계산 그래프
- 개념 설명: 계산 그래프는 어떤 연산의 결과가 다음 어떤 연산에 쓰이는지 기록한 연결이에요. 입력부터 결과까지의 과정을 살필 수 있고, 기울기를 구할 때 중간 결과와 연결을 재사용할 수 있습니다. 점의 위치 자체가 숫자의 크기를 뜻하지는 않아요.
- 언제 필요한가: 최종 답이 어떤 연산을 거쳐 나왔는지 살피고 기울기를 계산할 때 필요해요. 중간 결과와 연산의 연결을 기록해 다시 활용합니다.

- 목표: 결과값만 아는 것과 어떤 연산으로 얻었는지 아는 것의 차이를 이해한다.
- 예상 질문: '최종 답만 알면, 앞에서 쓴 숫자의 영향도 알 수 있을까요?'
- 3D 장면: S4의 같은 `u,v,a,p,L` 계산을 사용한다. '결과만 보기'에서는 마지막 값이 보이고, '과정 보기'에서는 연산 종류와 필요한 중간 값이 연결된 구조가 나타난다. 역방향 계산에서 사용하는 연산 기록을 강조한다.
- 주된 조작: `과정 펼치기`. 가려진 연산 의존성이 드러난 뒤 Q3.3의 역방향 계산을 재생한다.
- 화면 설명:

  > 예측이 4이고 틀린 정도가 16이라는 결과만으로는, 어떤 숫자가 얼마나 영향을 줬는지 알기 어렵습니다.
  > 무엇을 두 배 했고 무엇을 더했는지 과정이 연결되어 있으면 앞쪽 숫자의 영향을 계산할 수 있어요.
  > 자동미분 도구는 이런 계산의 연결과 연산별 미분 규칙을 이용합니다. 모든 과거 기록을 영원히 저장한다는 뜻은 아니에요.

- 이름 붙이기: 계산 그래프, 연산 기록, 자동미분.
- 이해 확인: '기억해야 하는 것은 마지막 답 하나뿐일까요, 계산의 연결도 필요할까요?'
- 연결: Q4.3, Q3.3.
- 주의: 모든 과거 기록이 무한히 저장된다고 설명하지 않는다. 실제 도구는 필요한 기록을 보관하고 그래프의 수명이 있다. `requires_grad`의 세부 동작은 보충 설명에서 다룬다.
- 교재 연결: PDF 86~88쪽.

### Q4.3 - 직접 하던 계산 중 무엇을 도구에게 맡길까?

- 개념 이름: 자동미분과 PyTorch
- 개념 설명: 자동미분은 기록한 연산의 연결과 연산별 미분 규칙으로 기울기를 계산하는 기능이에요. PyTorch는 숫자 배열 계산과 자동미분을 지원하는 도구입니다. 기울기를 구하는 backward()와 실제 값을 바꾸는 갱신은 별도 일이에요.
- 언제 필요한가: 반복되는 배열 계산과 기울기 계산을 도구에 맡길 때 사용해요. 어떤 문제를 풀고 무엇을 줄일지 정하는 일은 여전히 사람이 합니다.

- 목표: 사람이 정하는 문제·모델·손실과 도구가 수행하는 계산을 구분한다.
- 예상 질문: '바꿀 방향을 자동으로 계산하면 손잡이 값도 저절로 바뀔까요?'
- 3D 장면: S4의 왼쪽에는 Q3.3의 수동 기울기 계산, 오른쪽에는 같은 연산을 기록한 자동 계산을 표시한다. 같은 u·v에서 같은 기울기 -24·-8이 나온다. '값 고치기' 단계로 전환할 때에만 S3의 점과 손실이 바뀐다. 코드 전체보다 현재 단계에 해당하는 한 줄을 함께 보여준다.
- 주된 조작: `다음 학습 단계`. '기록 초기화 → 예측 → 손실 → 기울기 계산 → 값 갱신'을 순서대로 진행한다. 기록 초기화는 이전 기울기를 비우는 일이며 모델 값을 원래대로 되돌리는 것이 아니다.
- 화면 설명:

  > 어떤 문제를 풀지, 어떤 계산을 사용할지, 무엇을 틀린 것으로 볼지는 우리가 정합니다.
  > 자동미분 도구는 우리가 연결한 계산에서 기울기를 구해줍니다. 이때 손잡이 숫자가 저절로 바뀌지는 않아요.
  > 다음 갱신 단계에서 기울기를 이용해 실제 값을 바꿉니다. 그 뒤 새 예측과 틀린 정도를 다시 계산해 비교합니다.

- 이름 붙이기: PyTorch, Autograd, optimizer.
- 이해 확인: '`backward()`만 실행했다면 무엇이 생겼고, 무엇은 아직 바뀌지 않았을까요?'
- 연결: Q1.2로 돌아가 전체 학습 흐름 확인. '처음에 보았던 판단 기준의 변화가 이런 계산으로 이루어집니다.'
- 주의: 자동미분을 정답 생성, 모델 선택, 데이터 품질 보증과 혼동하지 않는다. 구현 시마다 새로운 순전파로 그래프를 만들고 의도하지 않은 `.grad` 누적을 피한다.
- 교재 연결: PDF 86~92쪽. 제공된 Tensor 노트북에 autograd 실습 전체가 들어 있다고 표시하지 않는다.

## 6. 화면에서 숨겨 두었다가 펼칠 수식·코드

### XOR 중간 계산 검산표

| x1 | x2 | h1=ReLU(x1-x2) | h2=ReLU(x2-x1) | h1+h2 | XOR 정답 |
|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 | 0 |
| 0 | 1 | 0 | 1 | 1 | 1 |
| 1 | 0 | 1 | 0 | 1 | 1 |
| 1 | 1 | 0 | 0 | 0 | 0 |

### 기울기와 갱신

```text
p=3u+v, L=(p-8)^2
dL/dp=2(p-8)
dL/du=6(p-8)
dL/dv=2(p-8)
u_new=u-lr*dL/du
v_new=v-lr*dL/dv
```

`u=1,v=1`에서 dL/dp=-8, dL/du=-24, dL/dv=-8이다. u의 두 경로 기여는 -16과 -8이다.

### 같은 계산을 하는 PyTorch 예시

아래는 구현 시 사용할 참조 코드다. 현재 문서 작성 과정에서는 PyTorch 런타임 실행 검증을 하지 않았으며 수치 예제는 독립 산술로 확인했다.

```python
import torch

u = torch.tensor(1.0, requires_grad=True)
v = torch.tensor(1.0, requires_grad=True)
optimizer = torch.optim.SGD([u, v], lr=0.025)

optimizer.zero_grad()
a = 2 * u
prediction = a + u + v
loss = (prediction - 8) ** 2
loss.backward()
# 이 시점: u=1, v=1. 기울기만 u.grad=-24, v.grad=-8.
optimizer.step()
# 갱신 후: u≈1.6, v≈1.2.

with torch.no_grad():
    new_prediction = 3 * u + v
    new_loss = (new_prediction - 8) ** 2
# 새 예측≈6, 새 손실≈4. 이전 loss 텐서가 자동 갱신되는 것은 아니다.
```

## 12. PDF 분석 화면의 현재 동작 계약

- 기본 OpenAI 분석: 연결한 개인 키 또는 표시된 서버 기본 연결로 전체 요약·개념·뜻·용도·쉬운 상황·관계 이유·근거 페이지를 만든다. 모델 출력의 구조와 실제 원문 인용을 검사한다. 로컬 구조 분석은 AI 없는 미리보기로 따로 선택한다.
- 지원 장면은 기존 Q ID로 연결하고 PDF 개념 ID와 구분한다. 모든 장면은 버튼을 눌렀을 때만 만든다. 지원하지 않는 개념은 근거 중심 설명과 선택형 관계 그림을 제공한다.
- 분석 중·실패·성공을 표시한다. 분석 실패 시 현재 지도를 유지하며 예시 지도 복귀 버튼을 제공한다.
- OpenAI 연결은 사용자가 개인 키·모델을 화면에서 설정하거나 서버 기본 설정을 이용한다. 추출 텍스트 전송·API 요금·키 수명을 알린다. 코드와 모의 테스트만으로 실제 모델의 설명 정확성·장면 선택 적합성을 검증했다고 보고하지 않는다.
- 스캔·암호화·손상 PDF, 허용 크기 초과, API 실패는 오류 안내 대상으로 관리한다. OCR과 임의 3D 생성은 지원하지 않는다.
- 통합 검증은 합성 PDF를 사용한다. 실제 교재의 추출 품질과 학습 효과는 별도 확인한다.

## 14. 문맥에 맞춰 보여주는 기초 용어 풀이

실제 PDF 설명에 해당 말이 등장할 때만 제공하는 검토된 보충 풀이이다. AI가 작성한 교재 설명과 구분한다. 시각화 장면을 이미 봤다고 가정하지 않는다.

| 용어 | 쉬운 뜻 |
|---|---|
| 가중치 | 입력의 각 특징을 얼마나 반영할지 정하는 숫자예요. 학습하면서 조정합니다. |
| 편향 | 입력에 곱하는 숫자와 별도로, 계산 결과에 더해 판단 기준의 위치를 옮기는 숫자예요. |
| 가중합 | 입력마다 가중치를 곱한 뒤 모두 더한 값이에요. 여기에 편향을 더해 다음 계산으로 보낼 수 있습니다. |
| 파라미터 | 가중치와 편향처럼 학습하면서 조정하는 숫자를 묶어서 부르는 말이에요. |
| 비선형 | 곱하고 더하는 하나의 선형 계산만으로는 나타낼 수 없는 변화예요. 음수를 0으로 바꾸는 ReLU가 한 예입니다. |
| 예측값 | 입력을 계산에 통과시켜 모델이 내놓은 답이에요. 실제 정답과 비교합니다. |
| 손실 | 예측이 얼마나 잘못됐는지 정해진 방법으로 나타낸 숫자예요. 어떤 설정이 더 나은지 비교하는 기준이 됩니다. |
| 기울기 | 지금 조절값을 아주 조금 바꿀 때 결과가 어느 방향으로 얼마나 변하는지 나타내는 값이에요. |
| 미분 | 현재 위치 근처의 작은 변화가 결과에 미치는 영향을 구하는 방법이에요. 학습에서는 손실을 줄일 방향을 알아보는 데 씁니다. |
| 연쇄법칙 | 여러 계산을 차례로 거친 변화의 영향을, 각 계산의 변화율을 이어서 구하는 규칙이에요. |
| 역전파 | 마지막 손실에서 계산 연결을 거슬러 가중치들의 기울기를 구하는 방법이에요. 이 단계에서 가중치 값을 바꾸지는 않습니다. |
| 경사하강법 | 구한 기울기를 이용해 손실을 줄이는 방향으로 실제 조절값을 바꾸는 방법이에요. |

## 16. 지원 개념의 검토된 연결 이유

분석 결과에 아래 두 개념의 연결이 있을 때 적용하는 보충 풀이이다. 새로운 개념이나 연결을 임의로 추가하지 않는다.

| 시작 개념 | 연결 개념 | 관계 | 이어지는 이유 |
|---|---|---|---|
| 머신러닝 | 지도학습 | 포함 관계 | 머신러닝에는 여러 접근이 있어요. 입력과 정답을 함께 쓰는 경우가 지도학습이에요. |
| 지도학습 | 회귀 | 문제 유형 | 지도학습에서 예측할 정답이 가격이나 길이 같은 연속적인 숫자라면 회귀 문제로 다뤄요. |
| 지도학습 | 분류 | 문제 유형 | 지도학습에서 정답이 스팸 여부처럼 정해진 종류 중 하나라면 분류 문제로 다뤄요. |
| 퍼셉트론 | XOR과 표현의 한계 | 표현의 한계 | 단순한 퍼셉트론이 만드는 선 하나로는 XOR의 네 점을 완전히 나눌 수 없어요. 숫자를 오래 조정하는 것과 계산 방식을 바꾸는 것을 구분하게 해줘요. |
| XOR과 표현의 한계 | 다층 퍼셉트론 | 다른 표현 | XOR처럼 선 하나로 나누기 어려운 관계를 중간 계산으로 다르게 표현해봐요. 다층 퍼셉트론에서도 층 수만 늘리기보다 중간 비선형 계산이 함께 중요해요. |
| 활성화 함수 | 다층 퍼셉트론 | 표현을 돕는 계산 | 곱하고 더하기만 여러 층 연결하면 하나의 선형 계산으로 정리할 수 있어요. 활성화 함수의 비선형 변화를 넣으면 다층 퍼셉트론이 표현할 수 있는 관계가 달라져요. |
| 활성화 함수 | ReLU | 함수의 예 | ReLU는 활성화 함수의 한 예예요. 중간 값이 음수면 0으로, 그 밖에는 그대로 보내는 규칙을 사용해요. |
| 순전파 | 손실함수 | 예측 평가 | 순전파가 만든 예측을 정답과 비교해요. 손실함수는 그 틀린 정도를 비교 가능한 숫자로 나타내요. |
| 손실함수 | 미분과 변화율 | 줄일 방향 찾기 | 손실은 얼마나 틀렸는지 알려주지만 어떤 가중치를 어느 방향으로 바꿀지는 그 숫자만으로 알 수 없어요. 미분으로 작은 변화가 손실에 미치는 영향을 알아봐요. |
| 미분과 변화율 | 연쇄법칙 | 연결된 변화 계산 | 조절값과 손실 사이에 여러 계산이 있을 때, 연쇄법칙으로 각 단계의 변화율을 이어서 전체 영향을 구해요. |
| 연쇄법칙 | 역전파 | 효율적인 기울기 계산 | 역전파는 연쇄법칙을 계산 연결에 적용하고 중간 결과를 재사용해 여러 가중치의 기울기를 효율적으로 구해요. |
| 역전파 | 경사하강법 | 계산 후 실제 갱신 | 역전파는 고칠 방향을 나타내는 기울기를 계산해요. 경사하강법은 그 기울기와 학습률을 이용해 가중치의 값을 실제로 바꿔요. |
| 경사하강법 | 학습률 | 한 걸음의 크기 | 경사하강법으로 실제 값을 바꿀 때 학습률이 한 번 움직일 크기를 조절해요. 너무 큰 걸음은 손실을 더 크게 만들 수도 있어요. |
| Tensor와 행렬 연산 | PyTorch | 숫자 계산 도구 | 텐서로 묶은 많은 숫자의 배열 연산을 PyTorch가 지원해요. 배열 모양만 바꾸는 일과 새 값을 계산하는 일은 구분해요. |
| 역전파 | 자동미분 | 기울기 계산 자동화 | 역전파의 기울기를 매번 손으로 구현하는 대신, 자동미분이 기록한 연산과 미분 규칙으로 그 계산을 도와줘요. 실제 값 갱신은 별도예요. |
| 자동미분 | PyTorch | 기능과 도구 | PyTorch는 자동미분을 제공하는 도구 중 하나예요. backward()로 기울기를 구하고 가중치 갱신은 별도 명령으로 실행해요. |
