# 배움의 숲 앱

PDF를 연결한 OpenAI로 분석해 큰 흐름과 개념의 뜻·용도·연결 이유를 살펴보는 한국어 로컬 시제품이다. 고정 예시 지도와 로컬 구조 분석은 제공하지 않는다.

## 실행

프로젝트 루트에서 의존성을 준비하고 실행한다.

각 컴퓨터의 간편 실행은 루트 `start.bat`(Windows), `sh start.sh`(macOS·Linux) 또는 `python run.py`를 사용한다. 처음 한 번 프로젝트 `.venv`에 실행 의존성을 설치한다. 자세한 설치·포트·개인 API 연결 방법은 [루트 안내](../README.md)를 따른다. 아래 직접 실행은 이미 의존성이 준비된 환경용이다.

```powershell
python -m pip install -r requirements.txt
python learning-forest/server.py --port 4173
```

이 폴더에서는 `python server.py --port 4173`이다. `http://127.0.0.1:4173`은 이 PC에서 접근하는 주소다. HTML 직접 열기나 정적 서버는 PDF/API 기능을 제공하지 않는다.

## 사용 흐름

1. 시작 화면에서 PDF를 올리거나 개인 OpenAI를 먼저 연결한다. 연결 전에는 PDF를 전송하지 않는다.
2. 연결한 OpenAI로 문서의 전체 요약·개념·관계를 만든다. 기본 모델은 항상 `gpt-4o-mini`이며 직접 다른 모델을 선택한 연결은 그 선택을 유지한다. 이전 `OPENAI_MODEL` 환경 설정은 기본값에 적용하지 않는다.
3. 큰 내용 묶음을 따라 개념을 선택하고 뜻·용도·가상 예·연결 이유·실제 원문 근거를 읽는다.
4. 필요할 때 시각화를 연다. 지원하는 13개 실험 또는 관계 그림만 만든다. 지원 실험과 관계가 모두 없으면 빈 그림 버튼을 제공하지 않는다.

지도는 1000px보다 넓은 화면에서 가로, 그 이하에서 세로로 이어진다. 카드의 개수·표시 범위·하단 동작을 같은 순서로 표시한다. 묶음을 열면 전체 개념을 볼 수 있고 다시 전체 지도로 돌아갈 수 있다. 작은 질문이 많으면 모두 보기와 간단히 보기를 제공한다.

## 기록과 저장 범위

이해 표시와 메모는 문서별로 이 브라우저의 localStorage에 저장한다. 진도는 학습자의 수동 표시이며 객관적 평가가 아니다. 저장이 막히면 현재 화면에서 유지하고 알린다. PDF 원문·본문·API 키는 브라우저 저장소에 저장하지 않는다.

같은 탭에서 시작 화면으로 갔다가 지도를 이어볼 수 있다. 새로고침 후 지도 데이터와 PDF 원문 링크는 복원되지 않는다. 분석 결과 저장/불러오기는 아직 미구현이다.

## OpenAI 연결과 데이터 흐름

개인 키는 브라우저별 서버 메모리 세션에 최대 1시간 보관한다. 쿠키는 무작위 핸들만 담고 HttpOnly·SameSite=Strict를 사용한다. 키는 로그·파일·브라우저 저장소에 저장하지 않으며 연결 해제·만료·서버 종료 시 제거된다. 키는 앱에서 직접 입력한다.

연결 확인은 모델 접근 조회이며 PDF 전송이나 생성 요청을 하지 않는다. 분석할 때 PDF를 이 PC 서버로 보내 텍스트를 추출하고 OpenAI로 전달한다. 모델 접근 확인이 사용 한도나 생성 품질을 보증하지는 않는다. API 요금은 키가 속한 프로젝트에 청구되며 ChatGPT 구독과 별개다.

서버 `.env`의 기본 키도 사용할 수 있지만 개인 연결이 우선한다. 만료된 개인 요청을 서버 기본 키로 자동 재시도하지 않는다. 공개 서비스용 계정 인증·HTTPS·장기 키 보관은 구현 범위가 아니다.

통신 실패는 API 인증 오류와 구분한다. 로컬 앱 링크·서버 연결 재확인을 제공하고 연결/유료 분석 요청을 자동 재시도하지 않는다. 실패 시 기존 지도를 유지한다. 옛 로컬 분석 요청은 422로 거부한다.

## 설명과 한계

- AI는 번호가 붙은 실제 원문 구간을 고르고 서버가 페이지·인용을 복원한다. 근거가 있다는 이유로 설명 전체가 정확하다고 보장하지 않는다.
- 긴 ML 기초 교재는 원문 기반 최대 32개 주제의 누락을 검사한다. 다른 분야 PDF를 모두 포괄하는 범위 검사라는 뜻은 아니다.
- ML/DL·NLP의 검토된 기초 풀이 47개와 관계 28개를 보강한다. 대소문자·공백을 정규화한 정확한 이름 대응에 적용하며 AI 초안·원문과 역할을 구분한다.
- 임의 3D 코드를 생성하지 않는다. Canvas 좌표 투영으로 검토된 학습 예제를 표현한다. PyTorch 코드는 참조이며 브라우저에서 실행하지 않는다.
- 30MB·400쪽 이하의 텍스트 PDF 대상이다. OCR·그림 의미 해석은 별도다. 교재 원본은 저장·배포하지 않는다.
- 실제 개인 API 및 92쪽 교재의 32개 생성은 이전 별도 검토에서 확인했다. UI-001의 검증은 합성 PDF·모의 OpenAI이며 새 NLP 유료 호출을 수행하지 않았다. 학습 효과는 아직 평가하지 않았다.

## 수정과 검증

콘텐츠 원칙과 설계서는 [원칙](../docs/CONCEPT_MAP_PRINCIPLES.md), [질문·실험과 보충 풀이](../docs/QUESTION_SCENARIOS.md)를 따른다. `scripts/build_content.py`로 시각화 시나리오·용어·보충 풀이를 생성한다. `dist/content.js`는 직접 수정하지 않는다. 고정 지도 데이터는 생성하지 않는다.

폰트는 로컬 나눔스퀘어라운드 3굵기다. 폰트 위계는 `typography.css`, 시작/흐름 배치는 `journey.css`, 공통 버튼·카드·간격·상태의 최종 기준은 `ui.css`다. 수치와 장면은 `math.js`·`scene.js`, 화면은 `app.js`, 분석·근거는 `server.py`·`pdf_analysis.py`에서 관리한다.

루트 `.\verify.ps1`는 수치·Python·13개 선택형 실험·5개 화면 폭·연결 오류·모의 PDF 흐름을 확인한다. 유료 API를 호출하지 않는다. 최신 결과는 `qa-output/verification.json`이며 과거 결과를 현재 코드의 근거로 쓰지 않는다.

전체 목표·미완료 계획은 [ROADMAP](../docs/ROADMAP.md), 현재 범위는 [STATUS](../docs/STATUS.md), UI·기능 검토는 [검토 기록](../docs/UI_REVIEW.md)을 따른다. 배포·공유 링크·외부 접속 검증은 보류 중이다.
