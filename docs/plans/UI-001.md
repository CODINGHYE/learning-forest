# UI-001 — 화면 일관성 정리와 이전 지도 경로 제거

- 상태: 완료 (학습자·다른 교재 품질 평가는 별도)
- 대상: 시작·개념지도·개념 상세·선택형 시각화·연결 창
- 시작 코드 버전: `04d4392`
- 관련 원칙·설계: CONCEPT_MAP_PRINCIPLES, QUESTION_SCENARIOS, HARNESS

## 목표와 범위

내용 길이와 개념 수가 달라도 카드·링크·버튼·펼치기·글자 위계가 같은 규칙으로 보이게 한다. 사용자 추가 요청에 따라 로컬 구조 미리보기와 고정 예시 지도 경로를 UI·서버·런타임 데이터에서 제거한다. 13개 검증된 선택형 3D 실험은 PDF 개념의 설명 도구로 유지한다. 배포하지 않는다.

## 완료 조건

- 5개 묶음·2/3/4개 이상의 개념·긴 제목에서 같은 행 카드의 높이와 하단 동작이 정렬된다. 내부 이동 화살표가 별도 줄에 떨어지지 않는다.
- 시작·지도·상세·연결 창의 버튼, 카드, 글자 위계를 공통 기준으로 관리한다. 큰 흐름은 한 방향으로 유지한다.
- 고정 예시 지도·로컬 분석 선택/엔드포인트·기본 지도 데이터가 제거되고 첫 화면은 PDF 업로드와 OpenAI 연결만 제공한다.
- 실제 사용자 지도는 확인 과정에서 재분석하거나 유료 재생성하지 않는다. 자동 검증은 격리된 합성 PDF·모의 OpenAI를 사용한다.
- 전체 검증과 화면 캡처를 확인하고 원칙·상태·운영 문서를 갱신한다. 학습자 이해도와 배포는 별도다.

## 진행·결정 기록

- 2026-11-16: 첨부 및 실제 NLP 지도에서 묶음별 높이·하단 동작 유무 차이, 본문 아래로 떨어진 이동 화살표, 5개 묶음의 좁은 가로 배치를 확인했다. 개념 클릭 메타데이터가 PDF 열기로 오해될 수 있는 점과 버튼/단계 번호 표현 차이도 점검한다.
- 로컬 분석에서 AI의 범위 검사에 쓰던 주제 탐색은 독립적인 원문 후보 탐색 함수로 분리한다. 로컬 지도를 만드는 기능은 남기지 않는다.

## 결과

- 설계 반영: 원칙 0.9.0, 질문·실험 설계, 목표·상태·검토 기록 갱신
- 구현: 공통 ui.css와 카드 구조·이동·펼치기·모달·빈 상태 수정. 로컬/고정 예시 지도 경로 제거. 47개 기초 풀이·28개 관계 및 문맥 용어 보강
- 자동 검증: `.\verify.ps1` 전체 통과. 수치 9개·Python 42개·13개 선택형 실험 및 1440/1000/768/390/320px. 최신 커밋·입력 해시는 `learning-forest/qa-output/verification.json` 참조
- 화면 확인: 실제 NLP의 기존 문제와 검증용 NLP 지도 개선 캡처 비교. 새 실제 시작 화면·연결 창의 모델 gpt-4o-mini와 legacy UI 부재 확인. 새 서버에서 옛 로컬 요청 HTTP 422 및 사용자 개인 재연결 HTTP 200 확인
- 학습자 확인: 미실시
- 후속 기능 검토: NLP 뜻·용도·가상 예와 관계 보강, 빈 시각화 버튼 수정. 미완료인 누락 검사·결과 저장/다시 열기·자기 설명 피드백·이름 별칭 대응은 [검토 기록](../UI_REVIEW.md)에 분리
- 배포: 미실시. 개인 연결을 유지하고 추가 유료 PDF 재생성은 요청하지 않음
