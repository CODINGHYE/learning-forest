# 화면 일관성 및 후속 기능 검토

- 날짜: 2026-11-16
- 범위: 시작 화면, PDF 상태·연결, 전체/묶음 지도, 개념 상세, 13개 선택형 실험, 오류·빈 상태
- 근거: 사용자 첨부와 기존 실제 NLP 화면, 합성 PDF/모의 OpenAI의 5개 화면 폭 검사, 화면 캡처, 콘텐츠 설계 검토
- 구분: 실제 학습자 이해도 평가 또는 새로운 NLP PDF 유료 생성 품질 평가가 아니다.
- 실행 확인: 새 로컬 앱의 시작/연결 화면과 기본 모델을 확인했다. 제거된 로컬 요청은 실제 서버에서 HTTP 422를 반환한다. 사용자가 다시 연결한 개인 OpenAI는 HTTP 200을 확인했고 유지한다.

## 발견한 UI 문제와 수정

| 문제 | 수정 | 확인 |
|---|---|---|
| 개념 수가 다른 카드의 높이가 달라 행이 들쭉날쭉함 | 같은 행 높이 맞춤, 카드 본문과 하단 동작을 분리 | 2·3·4개 개념 및 긴 제목, 같은 행 높이/버튼 하단 좌표 검사 |
| 일부 카드에만 모두 보기 링크가 있어 하단 구성이 다름 | 모든 카드에 개수·표시 범위·같은 하단 버튼 제공. 모두 노출된 경우 '묶음 자세히 보기' | 5개 묶음 모두 하단 동작 확인 |
| 이동 화살표가 본문 아래의 별도 줄에 떨어짐 | 본문과 오른쪽 화살표의 두 열 구조, 내부 이동은 → | 오른쪽 범위·이전 가상 요소 제거 검사 |
| PDF 쪽수 문구가 PDF를 여는 링크처럼 보이지만 개념으로 이동함 | '교재 근거 · N쪽' 메타데이터와 개념 이동 화살표로 분리 | 개념→상세와 실제 원문 새 창 링크 구분 |
| 5개 묶음·긴 제목이 중간 화면에서 지나치게 좁아짐 | 넓은 화면 가로, 1000px 이하 세로 흐름 | 1440·1000·768·390·320px에서 넘침·방향 검사 |
| 버튼 높이·크기·모서리가 화면마다 다름 | ui.css 공통 규칙: 46px 이상, 14px, 12px 모서리 | 보이는 기본 조작의 크기·반경 검사 |
| 단계 1·3은 배지인데 연결 영역만 제목 속 숫자 | 1·2·3 영역 배지 통일, 공통 제목 위계 | 전체 13개 상세·실험 화면 검사 |
| 전체 지도에서 사용할 수 없는 질문 필터가 노출됨 | 전체 지도에서는 필터 숨김, 묶음 안에서는 유지 | 전체/묶음 이동 확인 |
| 세부 질문을 모두 펼친 뒤 다시 접을 수 없음 | 펼치기/간단히 보기와 aria-expanded 제공 | 많은 개념의 양방향 탐색 검사 |
| 긴 연결 창에서 하단 동작이 화면 아래로 사라짐 | 배경 스크롤 잠금·모달 내부 스크롤·하단 동작 고정 | 모바일 연결 창 캡처 및 모델/키 흐름 검사 |
| 로컬 구조와 고정 예시 지도 경로가 새 흐름과 섞임 | 선택 UI·복귀 버튼·분석 함수·고정 지도 런타임 데이터 제거. 오래된 로컬 요청 거부 | UI 부재·초기 개념 0개·옛 Q 해시의 홈 복귀·서버 422 검사 |

## 작업 뒤 기능·설명 재검토와 보완

| 발견 | 반영 |
|---|---|
| 지원 실험과 관계가 모두 없는데 시각화 버튼을 누를 수 있음 | 빈 그림 생성 버튼을 숨기고 아직 지원하지 않는다는 안내 제공. 관계가 있는 개념은 관계 그림 유지 |
| 비 DL 개념에는 기존 ML 용어 풀이가 충분하지 않음 | NLP의 토큰·벡터·문맥 등 9개 풀이와 15개 개념의 뜻·용도·가상 예를 추가. 기존 32개와 합쳐 47개 관리 |
| 단어 번호와 Word2Vec 벡터, 정적/문맥 표현을 혼동할 수 있음 | 식별 번호와 학습된 특징 벡터의 역할, 같은 단어의 문맥 한계를 쉬운 상황으로 구분 |
| 인코더를 항상 하나의 고정 벡터로 설명하거나 모든 Seq2Seq가 어텐션을 쓴다고 오해할 수 있음 | 모델 구성에 따른 차이를 명시하고 인코더·디코더의 역할을 구분 |
| Transformer·BERT·GPT가 같은 이름의 단계처럼 보일 수 있음 | 구성 요소와 모델의 관계, 보는 문맥과 출력 방식의 차이를 보강. 원 논문·공식 문서 근거를 설계서에 기록 |
| 전체 요약과 예시가 추상적인 기술 나열로 끝날 수 있음 | 생성 원칙에 입력·처리·목표를 잇는 전체 요약, 낯선 말의 첫 풀이, 실제 문장/작은 숫자의 예를 요구 |
| 최종 보고서가 이전 브라우저 메타데이터를 읽을 수 있음 | 출력 경로를 통일하고 실행 고유 ID를 대조해 과거 기록 재사용을 거부 |

검토된 관계는 기존 16개에 NLP 12개를 더해 28개다. AI가 문서에서 선택한 개념·페이지를 바꾸거나 문서에 없는 노드/관계를 임의로 추가하지 않는다. 보충 설명을 원문 인용으로 표시하지 않는다.

## 아직 남은 기능 개선

1. **다른 PDF의 개념 누락 검사**: 현재 원문 기반 필수 주제 검사는 긴 ML 기초 교재가 중심이다. NLP 등 다른 교재의 핵심 주제를 전부 포괄한다고 보장할 수 없다. 실제 PDF 2~3개의 목차·본문 대조가 먼저 필요하다.
2. **분석 결과 저장·다시 열기**: 같은 탭 이어보기는 되지만 새로고침 뒤 지도와 PDF 원문 링크는 복원되지 않는다. 저장 범위·개인정보·재분석 비용을 정한 뒤 저장/불러오기를 설계해야 한다.
3. **자기 설명 피드백**: 현재 메모·이해 표시는 수동이다. '이 개념은 언제 필요하고 무엇과 이어지는가'에 쓴 답을 평가하는 기능은 미구현이다. 비전공자 2~3명의 답을 먼저 관찰해 평가 기준을 정한다.
4. **이름 표기 대응**: 영문/한글 별칭까지 동일 개념인지 판단하는 검토된 표가 더 필요하다. 현재는 대소문자·공백을 정규화한 정확한 이름 대응만 적용하므로 보충 풀이가 항상 붙는다고 보장하지 않는다.

위 항목은 미완료이며 이번 UI 수정의 자동 검사 성공으로 학습 효과나 모든 교재의 내용 정확성을 완료 처리하지 않는다. 배포는 하지 않는다.
