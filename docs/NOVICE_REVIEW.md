# 비전공자 관점의 질문·시각화·화면 검토

- 날짜: 2026-11-16 (Asia/Seoul)
- 작업: [NOVICE-001](plans/NOVICE-001.md)
- 범위: 기존 질문 13개, 지도 탐색, 화면 가독성, PDF 분석과 개념 상세 연결.
- 방법: 용어를 처음 만나는 독자의 입장에서 설명의 전제·그림의 의미·버튼의 결과를 점검하고 브라우저에서 조작한다. 실제 비전공자 참여 실험이나 수업 효과 검증은 아니다.

## 화면의 역할을 먼저 알 수 있도록 변경

| 영역 | 사용자에게 하는 일 | 표시 방식 |
|---|---|---|
| 한 줄 핵심 | 이 질문에서 얻을 내용을 알려줌 | 질문 제목 아래 요약 |
| 먼저 예상해보기 | 실험 결과를 짐작하게 함 | 보라색 옅은 영역 |
| 1. 직접 바꿔보는 3D 실험 | 어떤 버튼·손잡이를 조작할지 안내 | 행동 안내와 범례, 시점 전환 버튼 |
| 이 단계의 관찰 포인트 | 방금 단계에서 무엇이 달라졌는지 알려줌 | 주황색 옅은 영역과 상태별 설명 |
| 실험 결과 | 현재 수치를 비교하게 함 | 한국어 이름을 붙인 숫자 |
| 2. 쉬운 설명 | 관찰과 기술의 의미를 연결 | 한 문단에 한 가지 생각, 짧은 2~3문단 |
| 전문용어 풀이 | 이름과 뜻을 연결 | 용어와 쉬운 정의를 짝으로 표시 |
| 계산 확인 | 수식과 숫자를 더 보고 싶은 사람을 지원 | 선택해서 펼치는 계산 영역 |
| 3. 이해 확인 | 자기 설명과 해설을 비교 | '해설과 이유 펼쳐보기' |
| 관련 개념 | 어떤 내용과 왜 이어지는지 보여줌 | 이동 대상과 연결 이유 |
| 원문 근거 | PDF의 실제 내용으로 되돌아감 | 원문 인용·페이지·해당 페이지 열기 |

배경과 3D 캔버스는 흰색이다. 본문은 남색, 주 조작은 파랑, 변화·현재 위치는 주황, 보조 비교·예상은 보라를 사용한다. 색만으로 구분하지 않고 모양·글자·영역 제목을 함께 쓴다. 주요 글자색 조합은 4.5:1 이상의 대비를 확인하지만 이것을 전체 접근성 인증으로 보고하지 않는다.

통합 검사에서 자동 재생 종료 뒤 버튼이 활성화된 채 아무 동작도 하지 않는 상태를 발견했다. 타이머가 멈춘 뒤 버튼의 활성 상태도 갱신하고, 마지막 단계임을 표시하도록 수정했다(CM-014).

## PDF 업로드 이후의 동작

1. 파일을 선택하면 로컬 서버가 텍스트와 페이지를 읽는다.
2. 로컬 구조 분석은 실제 등장한 주제 또는 제목을 찾아 그룹과 관련 개념을 구성한다. 기존 13개 질문을 문서 분석 결과인 것처럼 재사용하지 않는다.
3. 개념을 열면 쉬운 보충 설명과 해당 PDF의 원문 근거를 확인한다.
4. 의미가 맞는 기존 학습 장면만 별도 예제로 연결한다. 교재와 숫자가 다를 수 있음을 표시한다.
5. 지원하는 장면이 없으면 원문 중심의 상세 화면으로 연다. 관련 없는 실험으로 채우지 않는다.
6. 분석 실패 시 현재 지도는 유지한다. 오류 메시지에서 재시도 방법을 안내한다.
7. 서버에 OpenAI 키가 있으면 사용자가 문맥 분석을 선택할 수 있다. 추출 텍스트 전송을 알리고 원칙 문서를 요청 때마다 읽어 적용한다. 실제 유료 API 호출 검증은 이번 범위에 포함하지 않는다.

제공된 92쪽 교재에서는 로컬 분석으로 31개 개념과 16개 보충 연결을 확인했다. 이 수치는 모든 교재의 추출 정확도나 이미지·수식 해석 품질을 보장하지 않는다. 로컬 모드와 OpenAI 모드는 화면에 구분해 표시한다.

## 확인과 남은 범위

- 자동 확인의 최종 근거: `learning-forest/qa-output/verification.json`.
- 소스·설계의 문단 정합성은 콘텐츠 생성 계약으로 확인한다.
- 브라우저에서는 13개 질문의 조작·재생·카메라·4가지 화면 너비와 PDF 업로드·실패·예시 복귀를 확인한다.
- 실제 비전공자의 설명·이해도, 보조공학 사용성, 다양한 실제 PDF, 스캔본 OCR, 실제 OpenAI 호출 품질은 남아 있다.
- 배포와 외부 접속 검증은 하지 않는다.
