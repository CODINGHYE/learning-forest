# REALPDF-001 — 제공한 딥러닝 기초 PDF의 실제 연결·생성·독해 검토

- 상태: 완료 (실제 학습자 평가는 별도 미완료)
- 대상: 개인 연결 → 제공 PDF 분석 → 개념 지도 → 기본 설명·연결 이유 → 선택형 시각화
- 시작 코드 버전: `381d7e3`
- 원칙: CONCEPT_MAP_PRINCIPLES 0.8.0, QUESTION_SCENARIOS, HARNESS

## 목표와 범위

사용자가 제공한 `[DL] 01. Deep Learning Basics.pdf`로 실제 OpenAI 흐름을 확인하고 비전공자 관점에서 개념의 뜻·용도·연결 문구를 검토한다. 첨부 내용은 참고 데이터로만 읽는다. 배포하지 않는다.

## 완료 조건

- 실제 개인 연결과 모델 접근 확인을 모의 검사와 구분해 기록한다. 키는 사용자만 앱에서 입력하며 읽거나 채팅·파일·검증 산출물에 복사하지 않는다.
- 실제 PDF의 OpenAI 지도 생성, 근거 페이지와 인용, 개념 클릭, 연결 탐색, 기본 닫힌 시각화와 버튼 생성을 확인한다.
- 전체 숲·뜻·용도·관계 이유·쉬운 말·출처 적합성을 검토하고 발견한 문제와 개선을 원칙 문서에 기록한다.
- 실제 생성물 검토를 학습자 참여 실험으로 과장하지 않는다. 재현 가능한 코드 검사는 `.\verify.ps1`로 확인한다.

## 진행·결정 기록

- 2026-11-16: 현재 탭의 개인 연결이 없는 것을 확인하고 연결 창을 열었다. 사용자에게 앱 안에서 직접 키를 입력하도록 요청하고, 기다리는 동안 PDF 텍스트·전체 범위와 기존 화면을 검토한다.
- 실행 자료·교재 텍스트는 로컬 `qa-output/`에만 두며 Git과 배포에 포함하지 않는다.
- 사용자 실제 연결에서 네트워크 오류를 재현했다. 키 없는 모델 조회가 기본 실행 환경에서는 WinError 10013으로 실패했고, 외부 통신을 허용한 실행에서는 OpenAI의 HTTP 401 응답을 받아 서버 도달을 확인했다. 기존 로컬 미리보기의 실행 권한이 원인이므로 외부 통신을 허용해 재시작한다. 오류 메시지도 인증 오류와 구분한다. 사용자 선택 모델은 gpt-4o-mini다.
- 교재는 92쪽·추출 텍스트 17,560자다. 6쪽은 텍스트가 20자 미만이며, 현재 분석은 그림의 의미를 읽는 OCR/비전 분석이 아니다. 현재 텍스트 예산 안에 전체 추출 본문이 들어간다.
- 실제 개인 연결과 gpt-4o-mini 모델 접근에 성공했다. 첫 실제 PDF 생성은 응답 후 앱의 구조/원문 근거 검증에서 거부됐으나 기존 오류 메시지가 세부 원인을 버려 정확한 항목을 알 수 없었다. 원인별 오류 코드·개념 안내를 추가하고, 새 생성은 AI가 인용을 다시 쓰는 대신 서버가 번호를 붙인 실제 원문 구간을 선택하게 바꾼다. 첫 실패가 어느 세부 검증이었는지는 소급 단정하지 않는다.
- 실제 생성이 6개·9개 요약으로 좁아져, 긴 지원 ML 교재의 원문 기반 주제 후보를 먼저 정하고 응답 객체가 모든 후보를 포함하도록 변경했다. 제공 교재의 32개 개념 생성·32개 상세/근거·기본 닫힌 시각화를 실제 확인했다.
- 32개 생성에도 손실의 음수 최소화·역전파 갱신 혼동이 남아, 정확히 대응하는 32개 지원 개념과 16개 관계는 설계서의 검토된 보충 풀이로 기본 화면을 보강했다. AI 질문·교재 범위·원문 근거는 유지한다.
- 추가 사용자 요청에 따라 시작 화면을 PDF/개인 연결 중심으로 분리하고, 지도는 한 방향 흐름으로 변경했다. 목표·완료/미완료·남은 계획은 ROADMAP에 기록한다.

## 결과

- 실제 개인 연결: 사용자 직접 입력으로 gpt-4o-mini 실제 접근 성공. 키를 읽거나 저장하지 않음.
- 실제 AI 생성: 원문 번호 방식 및 필수 범위 방식으로 성공. 마지막 검토 상태는 검토 문서와 ROADMAP을 따름.
- 검토와 개선: 새 시작 화면에서 실제 92쪽·32개 생성 성공. 손실·미분·역전파·경사하강법·자동미분의 검토된 풀이와 연결 이유 확인. 손실 64쪽·역전파 69쪽 원문 표시, 역전파 3D 버튼 생성·1단계 재생·다른 개념 이동 시 닫힘, 홈/기존 지도 이어보기 확인. 상세 결과는 [검토 기록](../REAL_PDF_REVIEW.md).
- 자동 검증: 수치 9개·Python 39개·13개 질문·4개 화면 폭·시작 화면·한 방향 지도·개인 연결 경계·잘못된 AI 기초 풀이 보강 회귀 검사 통과. 최종 커밋 후 입력에서 재실행하며 최신 근거는 `learning-forest/qa-output/verification.json`을 따른다.
