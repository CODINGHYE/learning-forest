# 실제 딥러닝 기초 PDF의 흐름·독해 검토

- 날짜: 2026-11-16
- 대상: 사용자가 제공한 `[DL] 01. Deep Learning Basics.pdf`, 92쪽
- 모델: 개인 연결의 `gpt-4o-mini`
- 구분: 실제 API·화면을 에이전트가 검토한 기록이다. 비전공자 학습자 참여 평가가 아니다.
- 원본 교재·API 키·전체 API 응답은 이 문서나 Git에 저장하지 않는다.

첫 실패가 어떤 세부 검증에서 발생했는지는 이전 코드가 정보를 버렸으므로 소급 단정하지 않는다. 원문 번호 방식의 생성 성공은 인용을 안정적으로 표시한다는 뜻이며, 설명 전체의 의미까지 자동 보증하지 않는다.

## 검토 기준

1. 전체 숲: 전반부의 모델/구조와 후반부의 학습/도구가 함께 있는가?
2. 뜻: 전문용어를 모르는 사람도 무엇을 계산하거나 바꾸는지 알 수 있는가?
3. 용도: 언제 필요한지가 정의의 반복이 아닌 상황으로 설명되는가?
4. 연결: 두 개념을 어떤 이유로 함께 살피는지, 계산과 갱신을 혼동하지 않는가?
5. 근거: 표시한 실제 문장·페이지가 해당 개념과 설명을 뒷받침하는가?
6. 시각화: 기본 상세는 닫혀 있고 필요한 예시만 버튼으로 만들 수 있는가?

## 개선 후 실제 재검토

1. 프롬프트만 강화한 실제 재생성은 9개에 머물렀다. 이후 긴 지원 ML 교재의 원문에서 주제 후보를 정하고, 구조화 응답에 32개 필수 항목을 요구했다. 실제 생성된 32개 상세·근거와 시각화 기본 닫힘을 순회 확인했다. 이는 이 교재의 지원 주제 범위이며 모든 PDF의 완전성을 보증하지 않는다.
2. 32개 응답에도 손실의 '음수를 최소화' 표현과 역전파/갱신 혼동이 남았다. 32개 정확히 대응하는 지원 개념의 뜻·용도·예시와 16개 핵심 관계를 설계서에서 관리하는 검토된 보충 풀이로 보강했다. 문서 분석·질문·선택 근거는 유지하고, 검토된 풀이와 실제 원문을 화면에서 구분한다.
3. 새 시작 화면에서 제공 PDF를 다시 분석해 92쪽·32개 생성 성공을 확인했다. 최종 화면에서 손실은 틀린 정도를 비교하는 숫자, 미분은 현재 위치의 변화율, 역전파는 기울기 계산, 경사하강법은 실제 값 갱신, 자동미분은 계산을 돕는 기능으로 구분되는지 확인했다. 손실 64쪽과 역전파 69쪽 원문 표시도 확인했다.
4. 역전파의 연쇄법칙·경사하강법·자동미분 연결 이유와 자동미분/PyTorch 연결을 확인했다. 낯선 말 풀이가 설명에 맞게 노출된다. 지원 밖 개념의 AI 초안은 의미 검토가 여전히 필요하다.
5. 역전파 시각화는 버튼으로 열렸고 0→1/4 단계 재생에서 영향 -8을 표시했다. 다른 개념으로 이동하면 시각화는 다시 닫힌다. 실제 값 갱신과 기울기 계산을 구분한다. 13개 전체 예제의 수치·조작 검증은 자동 검사로 별도 수행한다.
6. 시작 화면은 업로드·개인 연결 중심이며, 홈으로 이동한 뒤 '만든 지도 이어보기'가 같은 32개 지도로 복귀한다. 재분석 요청이 없다는 것은 자동 UI 요청 횟수 검사로 확인했다. 실제 화면의 개인 연결 상태도 유지됐다. 데스크톱 가로/모바일 세로 흐름과 4개 폭은 자동 검사·화면 캡처로 확인했다.

실제 비전공자 이해도, 다른 교재의 내용 정확도, 스캔/그림 중심 PDF, 실제 모바일 PDF 뷰어와 보조공학은 미확인이다. [목표와 남은 계획](ROADMAP.md)에서 별도로 관리한다. 배포는 하지 않았다.
