# OPENAI-001 — 개인 OpenAI 연결과 PDF의 숲 중심 탐색

- 상태: 완료
- 대상: 개인 연결·해제·PDF 기본 분석 흐름·개념 뜻/용도/의미 관계·선택형 시각화
- 시작 코드 버전: `6094c52`
- 기준: CONCEPT_MAP_PRINCIPLES, HARNESS, OpenAI 공식 인증·모델 조회 문서

## 목표와 범위

서버 환경 파일을 수정하지 않고 각 사용자가 자신의 API 키와 모델을 연결해 PDF를 분석한다. 기존 로컬 분석과 귀여운 UI를 유지한다. 공개 배포는 하지 않는다.

추가 사용자 지시: PDF→연결된 OpenAI로 전체 지도→개념 클릭 시 설명을 기본 파이프라인으로 한다. 비전공자가 PDF의 개념과 그 연결성을 설명하는 것이 핵심 목표다. 시각적 예시는 별도 버튼을 눌렀을 때만 만든다. 기본 로컬 분석·자동 3D 중심 흐름을 변경한다.

## 완료 조건

- 연결 창에서 API 키·모델을 입력하고 키와 모델 접근을 확인한다. 모델 조회만 수행하며 연결 확인으로 문서를 전송하거나 생성을 요청하지 않는다.
- 키는 서버 메모리의 브라우저별 세션에만 둔다. 브라우저 저장소·URL·로그·응답 본문·Git에 남기지 않는다. HttpOnly·SameSite 세션 쿠키로 요청을 구분하고 연결 해제·만료·서버 종료로 제거한다.
- 개인 연결과 서버 기본 연결을 구분한다. 만료된 개인 연결이 다른 키로 조용히 대체되지 않는다. 문서 분석은 OpenAI 모드를 명시적으로 선택했을 때만 실행한다.
- 인증 실패·모델 권한·한도·연결 오류를 쉽게 알리고 기존 지도와 기존의 유효한 연결을 보존한다.
- 여러 사용자 키 분리·삭제·만료·비노출·UI 성공/실패와 기존 전체 검사를 모의 API로 검증한다. 실제 키·유료 요청은 테스트에 사용하지 않는다.
- PDF 전체 요약과 의미 관계 지도, 개념의 독립적인 뜻·용도·연결 이유가 먼저 보인다. 모든 3D 예시는 버튼 클릭 전 생성하지 않으며, 미지원 개념에는 근거 있는 관계 그림을 제공한다.

## 결정 기록

- 2026-11-16: 브라우저에 키를 지속 보관하지 않고 서버 메모리에 1시간만 연결한다. 연결은 같은 브라우저에서 새로고침해도 유지된다. 서버 재시작 시 연결이 해제된다.
- ChatGPT 로그인·구독과 API 연결의 차이, API 분석의 별도 사용 요금을 연결 화면에 알린다.
- 초기에는 기존 모델을 유지했으나 후속 사용자 요청(CM-028)으로 기본값을 항상 `gpt-4o-mini`로 변경했다. 사용자가 직접 모델 ID를 변경한 연결은 선택을 유지한다. 연결 확인은 모델 조회 권한 검사이며 생성 품질·잔액·모든 API 권한의 보증은 아니다.
- PDF 우선 선택 시 파일을 탭 메모리에 잠시 대기시키고 연결 후 분석한다. 취소하면 전송하지 않는다. 로컬 미리보기는 명시적 대안으로 유지한다.
- 지도는 일렬 학습 순서 대신 관계 종류와 개념 이웃을 표시한다. 한 그림에는 가까운 연결 최대 4개를 보여주고 범위를 알린다. 전체 개념은 묶음 목록으로 탐색한다.
- 기본 개념 이름·정의·용도를 설계서 필드로 추가하고 기존 수치·장면 설명은 선택형 실험 아래에 둔다. 12개 의미 연결의 이유도 설계서에서 생성한다.
