## 이번 실행 결과

DESIGN-001에서는 참고 HTML의 지도·상세 구성을 적용하고, 사용자의 추가 요청에 따라 귀여운 UI와 둥근 한글 글꼴·읽기 우선순위를 반영했다. 수치 9개·Python 24개·질문 13개·4개 화면 폭·PDF 성공/실패/복귀와 새 탐색·저장·글꼴 검사를 통합 명령으로 확인한다. 가장 최근 근거는 `learning-forest/qa-output/verification.json`의 상태·HEAD·입력 해시·실행 시각·검사별 결과다. 문서 정리와 커밋 후에도 최종 입력에서 다시 실행하며, 과거 보고서를 현재 코드의 통과 근거로 사용하지 않는다.

## 다음 작업

1. 실제 교재의 표·수식·목차로 인한 개념 오탐과 누락을 평가한다.

3. 학습자가 예측→조작→자기 말 설명을 수행하게 해 오해를 수집한다.

현재 합성 PDF 검증은 다양한 실제 교재에 대한 정확도나 OCR 지원을 의미하지 않는다. 스캔 PDF는 OCR이 별도로 필요하며, 임의 개념의 3D 실험을 생성하는 기능은 없다.

## DESIGN-001 반영 내용

- 왼쪽 사이드바를 상단의 학습 흐름 지도로 옮기고 아래에 독립된 질문 상세 카드를 배치했다. 작은 화면에서는 세로 지도다.
- 자체 책 길잡이 SVG, 둥근 단계, 입체감 있는 버튼을 적용했다. 흰 배경과 파랑·보라·주황의 역할을 유지한다.
- 진도는 학습자가 직접 이해 표시한 질문 수로 계산하며 해제할 수 있다. 질문을 잠그지 않는다.
- 개인 메모와 이해 표시는 PDF 내용으로 구분한 브라우저 저장 영역에 둔다. PDF 원본·본문을 브라우저 저장소에 저장하지 않는다. 저장이 막힌 경우 세션 유지와 안내를 제공한다.
- 네이버 공식 나눔스퀘어라운드 WOFF2 3굵기와 OFL을 앱에 포함했다. 질문 26~36px, 영역 19~20px, 설명 17~18px와 1.95 줄간격으로 구분한다.
- 실제 학습자 평가, 실제 유료 API 호출, 배포는 수행하지 않았다.
