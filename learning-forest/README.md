# 배움의 숲

질문 13개를 선택해 3D 장면과 쉬운 설명을 살펴보는 한국어 딥러닝 학습 시제품입니다.

## 실행

`dist`를 정적 HTTP 서버로 열면 됩니다. 빌드와 외부 JavaScript 라이브러리, API 키가 필요하지 않습니다.

```text
python -m http.server 4173 --directory dist
```

실제 환경에 설치된 Python 실행 경로를 사용하세요. `http://127.0.0.1:4173`에서 확인합니다.

## 관리

- `../docs/CONCEPT_MAP_PRINCIPLES.md`: 작성 원칙과 오류 기록.
- `../docs/QUESTION_SCENARIOS.md`: 질문별 설계와 대본.
- `scripts/build_content.py`: 설계서에서 제목·설명·근거를 추출해 `dist/content.js` 생성.
- `dist/math.js`: 분류, XOR, 손실, 갱신, 간단한 역방향 자동미분과 Tensor 계산.
- `dist/scene.js`: Canvas 2D 위에서 3D 좌표를 투영하고 면·선·점을 깊이순으로 그리는 렌더러.
- `dist/app.js`: 지도, 질문, 조작, 단계 재생, 설명 연결.

3D 장면은 실제 좌표와 함수값으로 계산합니다. WebGL이나 GPU 사용을 요구하지 않습니다. 자동미분 장면은 브라우저의 작은 계산 그래프 엔진을 실행하며, 펼침 코드에는 동일 계산의 PyTorch 표현을 제공합니다. PyTorch 자체를 브라우저에서 실행하지는 않습니다.

## 현재 상태와 확인 범위

- 로컬 구현: 큰 질문 4개, 작은 질문 13개, 다섯 3D 무대, 단계 재생, 설명·힌트·자료 위치 연결.
- 자동 확인: 수치 테스트 9개 통과. 질문 13개와 화면 너비 1440·768·390·320px에서 조작 및 가로 넘침 확인. 카메라 변경이 학습값을 바꾸지 않는지 확인.
- 사용자가 보는 로컬 미리보기: `http://127.0.0.1:4173`. 이 주소는 사용자 PC에서만 접근할 수 있다.
- 실제 학습자의 이해도 평가와 최종 완성도 검토는 진행하지 않았다.
- 2026-11-16 사용자 요청에 따라 배포·공유 링크 생성·외부 접속 검증을 보류했다. Site ID는 `.openai/hosting.json`에 저장되어 있으므로 나중에 같은 Site를 이어서 사용한다. 현재 배포된 버전은 없다.

현재 범위는 설계한 수업의 질문 지도와 장면입니다. PDF 업로드로 임의의 교재를 분석하거나 OpenAI API를 호출하는 기능은 아직 구현하지 않았습니다. '내 교재 연결'은 선택한 PDF를 사용자 브라우저에서만 열며 서버로 업로드하지 않습니다. 수업 원본 PDF와 노트북은 배포하지 않습니다.
