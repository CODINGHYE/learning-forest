# DESIGN-001 — 참고 HTML을 반영한 로드맵과 상세 카드

- 상태: 완료
- 대상: 전체 지도·질문 상세·학습 진도·개인 메모
- 시작 코드 버전: `2e1461a`
- 기준: CONCEPT_MAP_PRINCIPLES, QUESTION_SCENARIOS, 사용자 제공 concept_map.html

## 목표와 범위

참고 파일의 가로 흐름 지도, 선택 상태, 독립된 상세 카드, 진도·메모 구성을 기존 학습 기능에 적용한다. 흰 배경·쉬운 역할 이름을 유지하고 실제 PDF 지도와 13개 실험을 보존한다. 첨부 HTML의 코드와 외부 CDN은 실행하거나 서비스에 복사하지 않는다. 배포하지 않는다.

## 완료 조건

- 큰 질문을 위쪽 흐름에서 고르면 세부 질문이 그 아래에 나타난다. 모바일에서도 큰 질문 묶음이 먼저 유지된다.
- 질문 상세에서 이전·다음 이동, 직접 이해 표시, 문서별 개인 메모가 동작한다. 진도는 이해 표시 기준이며 객관적인 숙련도 평가가 아니다.
- 업로드한 PDF의 실제 개념 수·묶음 수를 사용한다. 참조의 고정된 5단계를 복사하지 않는다.
- 기존 통합 검사와 새 탐색·메모·진도 검사를 통과하고 데스크톱·모바일 화면을 검토한다.

## 진행·결정 기록

- 2026-11-16: 기존 사이드바를 상단 지도 카드로 변경한다. 지도 연결은 학습 안내이며 발명 순서가 아님을 표시한다.
- 학습 설명의 편집 기능은 추가하지 않는다. 검토된 설명 원본과 개인 메모를 분리한다. 메모·이해 표시만 브라우저에 저장한다.
- 추가 사용자 요청: 듀오링고처럼 귀여운 UI. 자체 책 길잡이 SVG, 둥근 단계, 눌리는 버튼을 적용한다. 흰 배경과 파랑·보라·주황 의미 구분을 유지한다.
- 추가 사용자 요청: 둥글고 읽기 좋은 글꼴과 중요도 구분. 네이버 공식 WOFF2 3굵기를 내려받아 앱에 포함하고 OFL을 보존한다. 질문 26~36px, 영역 19~20px, 설명 17~18px와 줄간격 1.95를 적용한다. Canvas도 글꼴 로딩 후 다시 그린다.
- 중간 검증에서 새 탐색 검사 후 화면 폭을 390px로 복구하지 않아 기존 PDF 검사가 잘못된 폭으로 비교했다. 테스트의 화면 폭을 명시해 수정했고 전체 통과를 확인했다.

## 결과

- 설계 반영: 원칙 0.5.0 및 공통 학습 경험에 반영. 질문 ID와 학습 설명 원본은 유지한다.
- 구현: 상단 지도·반응형 상세 카드·이전/다음·직접 이해 표시와 필터·문서별 개인 메모·자체 SVG 길잡이·로컬 한글 글꼴 3굵기와 글자 위계.
- 자동 검증: `.\verify.ps1` 전체 통과. 수치 9개·Python 24개·13개 질문·4개 화면 폭·PDF 검사와 새 탐색·저장·문서 분리·저장 실패·글꼴 로딩·읽기 계층 검사가 통과했다. 생략 0개, 브라우저 런타임 오류·외부 요청 0개다. 최종 상태와 입력 해시는 `learning-forest/qa-output/verification.json`을 따른다. 결과 문서 반영·커밋 후 최종 입력에서 같은 명령을 다시 실행한다.
- 화면 검토: 에이전트가 데스크톱 지도, 상세 설명·메모, 모바일 실험 캡처를 확인했다. 실제 학습자 검토와 구분한다.
