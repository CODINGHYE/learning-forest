# 배움의 숲 — 최종 목표와 실행 계획

- 갱신일: 2026-11-16
- 범위: 로컬 시제품. 공개 배포는 보류한다.

## 최종 목표

비전공자가 수업 PDF를 넣고, 그 문서에 어떤 개념이 있는지와 각 개념의 뜻·필요한 상황·이어지는 이유를 자기 말로 설명할 수 있게 한다. 시각화는 이해를 돕는 선택 도구다. 앱 기능의 동작 확인과 실제 학습 효과 확인은 구분한다.

## 사용 흐름

**시작 화면(PDF 올리기·개인 OpenAI 연결) → 문서 분석 → 한 방향 개념지도 → 개념의 뜻·용도·연결 이유 → 필요할 때 시각화**

지도는 넓은 화면에서 왼쪽→오른쪽, 1000px 이하 화면에서 위→아래로 읽는다. 이해를 돕는 배치이며 기술의 발명 순서나 모든 학습자의 필수 경로를 뜻하지 않는다.

## 계획과 상태

| 계획 | 상태 | 완료 기준과 확인 범위 |
|---|---|---|
| P1. 학습 목표·질문·원칙 정리 | 완료 | 뜻·용도·연결 중심 목표와 수정 원칙을 문서로 관리 |
| P2. 간결한 시작 화면 분리 | 완료 | PDF 업로드·OpenAI 연결·기존 지도 이어보기. 로컬 구조·고정 예시 지도 제거. 5개 화면 폭 검사 |
| P3. 한 방향 개념지도 | 완료 | 브레인스토밍형 중심 그림 제거. 가로/세로 단계 배치·개념 선택·이전/다음 이동 검사 |
| P4. 개인 OpenAI 실제 연결 | 완료 | 사용자가 앱에서 직접 키 입력, gpt-4o-mini 모델 접근·실제 PDF 요청 확인. 키는 임시 메모리 보관 |
| P5. 교재 전체 범위·원문 근거 | 완료 | 제공된 92쪽 PDF의 32개 원문 주제 확인·필수 응답 검사·실제 생성. 원문 번호로 페이지/인용 복원 |
| P6. 비전공자 기본 풀이 보강 | 완료 | ML/DL·NLP의 47개 기초 개념·28개 핵심 연결을 보충 풀이로 관리. AI 초안과 원문을 구분하고 대응 개념만 보강 |
| P7. 선택형 시각화 | 완료 | 기본 닫힘. 13개 지원 3D 예제와 다른 개념의 연결 그림을 버튼으로 생성 |
| P8. 새 시작 화면부터 실제 교재 흐름 재확인 | 완료 | 실제 92쪽·32개 생성, 손실·미분·역전파·경사하강법·자동미분 풀이와 연결·근거·3D 단계 재생·홈 이어보기 확인 |
| P9. 실제 비전공자 이해도 확인 | 미완료 | 동료가 개념의 뜻과 연결 이유를 자기 말로 설명하는지 확인해야 함 |
| P10. 다른 실제 교재로 품질 확인 | 미완료 | 서로 다른 PDF 2~3개에서 누락·오탐·용어 난도·연결 이유를 비교해야 함 |
| P11. UI 일관성·legacy 제거·후속 검토 | 완료 | 카드·버튼·화살표·빈 상태·5개 화면 폭 및 기능 검토. [검토 기록](UI_REVIEW.md) |
| P12. 분석 결과 저장·다시 열기 | 미완료 | 새로고침 뒤 재생성 없이 지도 복원하는 방식과 저장 범위 설계 필요 |
| P13. 자기 설명 피드백 | 미완료 | 학습자 답을 관찰해 뜻·용도·연결 평가 기준부터 정해야 함 |
| P14. 각 PC 로컬 실행·비공개 GitHub 공유 | 진행 중 | 간편 실행·의존성·안내·깨끗한 복사본 검사 완료. 원격 main 업로드 확인 후 완료 |
| 공개 배포·공유 링크 | 보류 | 사용자가 다시 요청하기 전까지 진행하지 않음 |

## 앞으로 남은 계획

1. P9: 비전공자 동료 2~3명에게 '손실은 언제 필요한가', '미분·역전파·경사하강법은 어떻게 다른가', '텐서와 PyTorch는 어떻게 이어지는가'를 자기 말로 설명해보게 한다.
2. P10: 다른 실제 PDF 2~3개로 개념 누락과 관계 오류를 검토한다. 현재 검토된 기초 풀이의 지원 범위를 벗어난 내용은 AI 초안으로 구분한다.
3. 동료 평가와 다른 교재 검토에서 나온 문제를 원칙 문서에 기록하고 설명·연결·시각화의 우선순위를 다시 정한다.
4. P12~13: 분석 결과 저장/다시 열기, 자기 설명 피드백을 설계한다. NLP 등 다른 교재의 누락 검사와 영문/한글 별칭 대응도 [후속 검토](UI_REVIEW.md)에 따라 우선순위를 정한다.

학습자가 답하지 않은 상태에서 학습 효과를 완료로 표시하지 않는다. 최신 코드 검사 근거는 `learning-forest/qa-output/verification.json`, 실제 교재 검토는 [검토 기록](REAL_PDF_REVIEW.md)을 따른다.
